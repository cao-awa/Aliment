# Aliment

**A Minecraft mod about physiology, disease, pharmacology, and contagion.**

Target Version: **Minecraft 26.3** (Fabric, Scala 3.9 / Kotlin 2.4 / Java 25).

---

## Core Features

- **Realistic Infection and Immune Dynamics**: Eating spoiled food does not deal instant health damage. Pathogens reproduce according to logistic population growth models. The immune system's clearance efficiency follows a bell-shaped curve: insufficient inflammation fails to recruit white blood cells, while runaway inflammation triggers life-threatening cytokine storms that damage host tissues.
- **Dynamic Physiological Balance**: Introduces an independent 10-pip thirst meter, along with serum electrolyte homeostasis (sodium, potassium, magnesium, chloride, calcium) and trace micronutrients (iodine, vitamin C). Maintain bodily equilibrium to avoid dehydration, electrolyte disturbances, hypothyroidism, and scurvy.
- **Herbal Medicine and Pharmacological Interventions**:
  - **Willow**: Riparian ecosystem; strip willow bark and brew willow bark soup in cauldrons to extract natural antipyretic salicin for fever relief and analgesia.
  - **Ephedra**: Arid shrub; grind or snip twigs to produce ephedrine potions granting digging haste and heightened alertness.
  - **Coptis and Phellodendron**: Traditional bitter medicinal herbs rich in berberine; consume raw or grind to brew potions that specifically arrest bacterial replication.
  - **Licorice**: Antiviral herb rich in glycyrrhizin; chew roots or grind to brew potions that inhibit viral replication and soothe inflammation.
  - **Mandrake and Gymnopilus**: Explore dangerous anticholinergic nightshades and psychoactive mushrooms, experiencing pupil dilation, blurred vision, and vivid perceptual distortions.
  - **Dexamethasone**: High-potency glucocorticoid injection designed as an emergency clinical countermeasure to halt severe cytokine storms.
- **Crafting and Agricultural Expansion**:
  - Rock salt mining, multi-stage grindstone pulverization, and salt crystallization.
  - Submarine seaweed aquaculture, culinary baking, grindstone milling, and seaweed iodized salt synthesis, establishing an iodine metabolic chain against hypothyroidism.
  - Glass fermentation tanks and condenser pipe distillation systems to brew wines of varying alcoholic strengths.
  - Complete decorative willow wood building set and cascading willow tree canopies overlooking water bodies.

## Environment and Building

| Component | Requirement |
| --- | --- |
| Minecraft | **26.3** |
| Loader | Fabric Loader ≥ 0.19.5, Fabric API ≥ 0.161.0+26.3 |
| Runtime Environment | Java 25, Kotlin 2.4.20, Scala 3.9.0 |
| Build Tool | Gradle 9.7.1 + Fabric Loom 1.17.21 |

```powershell

# Compile and build jar
gradle build

# Launch dev client and dedicated server
gradle runClient
gradle runServer

# Regenerate assets, data, and textures (idempotent)
tools\gen_data.cmd
tools\gen_textures.cmd
```
