# 数学模型

Aliment 的生理系统是一个**离散时间动力系统**：每个玩家一个状态向量，每服务器刻推进一步。本文写出
它依据的每一条公式、公式里的每一个常数，以及这个形状背后的理由。

它是写给**想改模型**而不是想读模型的人的。[PHYSIOLOGY.md](PHYSIOLOGY.md) 讲每个量的临床含义，
[SPOILER.md](SPOILER.md) 讲玩家感受到什么，而这一篇讲的是代数：谁是谁的函数，哪些项是相加、哪些
是相乘，以及在边界上会发生什么。

公式以 **LaTeX** 排版，写在 `$…$` 与 `$$…$$` 里，在 GitHub、VS Code 的 Markdown 预览以及大多数
Markdown 阅读器中都能正常渲染。每一条都在 `typewriter` 里点明它所依据的源码常数，所以本文的任何一个
断言都能用一次搜索回到代码里核对。

这里的一切只存在于两个文件里，别无他处：

| 文件 | 内容 |
| --- | --- |
| `src/main/scala/.../physiology/model/Model.scala` | 状态类型、参考范围，以及 `ModelConstants`——每一个标量 |
| `src/main/scala/.../physiology/model/Physiology.scala` | 每一条公式，以及不在 `ModelConstants` 里的局部速率 |

两者都不 import Minecraft、Kotlin 或 Fabric。模型是**纯数字的函数**，这正是它无需世界即可测试的原因，
也是下文所有数字成立的前提。

## 1. 约定

### 1.1 离散时间

时间单位是**一个服务器刻**，一个 Minecraft 日是

$$T_{\text{day}} = 24\,000 \text{ 刻}.$$

模型里每个速率都按刻计，且大多写成精确的除法，好让那个标志性数字一眼可读，而不是被冻结成小数：

$$r_w = \frac{100}{5 \times 24\,000} \quad (\texttt{WATER\_DECAY\_PER\_TICK})$$

这是刻意的。*五天掉 100* 表达了意图，并且在 tick rate 改变时依然成立；字面量做不到这一点。下文中
凡以"每刻 X"形式给出的速率，旁边都附了推导。

积分格式是**显式欧拉法**：每一步读刻开始时的状态，写刻结束时的状态，

$$\mathbf{s}_{t+1} = F(\mathbf{s}_t),$$

没有子步进，也没有求解器。这在此处是合适的，因为模型里每一个速率都比最快那个量的稳定上限低了若干个
数量级（见 §18），所以欧拉法与精确解之间的差别远低于玩家或测试所能观察到的分辨率。

| 微量元素 | $I, A$ | µmol/L | 碘与维生素C——千分之一 mmol，因为它们的整个范围还不到一个 mmol |
| 血糖 | $g$ | mmol/L | |

### 1.3 两个原语

模型里几乎每一条公式都由这两个之一构成。

**压进区间。** 它出现在几乎每一步的末尾，好让任何失控的值都到不了荒谬的地步：

$$\mathrm{clamp}(x,\, a,\, b) = \begin{cases} a, & x < a \\[2pt] x, & a \le x \le b \\[2pt] b, & x > b \end{cases}$$

**一刻内向目标走一步。** 每刻吃掉剩余距离的 $k$ 那一部分：

$$\mathrm{approach}(x;\, \mu,\, k) = \mathrm{clamp}\big(x + (\mu - x)\,k,\; 0,\; 100\big)$$

记差距 $e_t = \mu - x_t$，递推就是 $e_{t+1} = e_t (1 - k)$，于是

$$e_n = e_0 (1-k)^n .$$

它在 $0 < k < 1$ 时永不超调，而它的**时间常数是 $\tau = 1/k$ 刻**：

$$(1-k)^{1/k} \xrightarrow[\;k \to 0\;]{} e^{-1} \approx 0.368,$$

所以过 $1/k$ 刻填掉约 $63\%$ 的差距，过 $3/k$ 填掉约 $95\%$。凡是模型想让一个量**趋近**某个值而不是
直接跳到那里，用的就是这个形状，而那个乘数是由想要的时间常数倒推出来的：$k = 0.002$ 给出 $500$ 刻
（$25$ 秒），$k = 0.0005$ 给出 $2\,000$ 刻，$k = 0.0004$ 给出 $2\,500$ 刻。

有一个命名上的注意点：`Physiology.scala` 里那个**有名字的辅助函数** `approach` 只服务于介质——它把
`MEDIATOR_APPROACH` 写死在里面，并钳到 `MediatorLevels.MAX` $= 100$。胰岛素（§12.1）、体温（§8.2）
与各种矿物（§10）用的是同一个指数形状，但各自带常数、各自带边界，而且是内联写的。请把 $k$ 与钳制
范围读作参数，而不是那个辅助函数的属性。

第三种构件出现在速率被写成"一段时间内的**总量**"的地方——一种"一天从上限 $C$ 代谢干净"的药：

$$r = \frac{C}{T} \quad\text{例如}\quad r_{\text{eph}} = \frac{5}{24\,000} \quad (\texttt{EPHEDRINE\_DECAY\_PER\_TICK})$$

注意这是**线性**（零级）消除，不是指数：每刻固定掉那么多，不管还剩多少。§13 说明哪些药走哪一种、
以及为什么。

## 2. 状态向量

模型的全部输入与输出就是一个向量；其余一切都是导出的。

$$\mathbf{s} = \big(\underbrace{H, P, L, C, B}_{\text{介质}},\; b,\, v,\; w,\; \underbrace{\mathrm{Na}, \mathrm{K}, \mathrm{Mg}, \mathrm{Cl}, \mathrm{Ca}}_{\text{电解质}},\; \underbrace{I, A}_{\text{微量元素}},\; \Theta,\; \pi,\; \alpha,\; \mathbf{d},\; \varepsilon,\; g,\; n\big)$$

| 分量 | 符号 | 范围 | 含义 |
| --- | --- | --- | --- |
| 介质 | $H, P, L, C, B$ | 各 $0..100$ | 组胺、前列腺素、白三烯、细胞因子、缓激肽 |
| 细菌、病毒 | $b, v$ | 各 $0..100$ | 分开跟踪 |
| 水量 | $w$ | $0..200$ | $100 = $ 正常 |
| 电解质 | $\mathrm{Na}, \mathrm{K}, \mathrm{Mg}, \mathrm{Cl}, \mathrm{Ca}$ | mmol/L | 见 §3 |
| 微量元素 | $I, A$ | µmol/L | 碘、维生素C |
| 体温 | $\Theta$ | °C | |
| 致热原 | $\pi$ | $-6..+6$ | 注入式调定点偏移 |
| 免疫闩锁 | $\alpha$ | $\{0, 1\}$ | 主动免疫是否已经启动？ |
| 药物 | $\mathbf{d}$ | | $12$ 种化合物 |
| 酶 | $\varepsilon$ | $0..100$ | CYP3A4 活性 |
| 血糖 | $g$ | $0..30$ | mmol/L |
| 胰岛素 | $n$ | $0..60$ | 指数 |

写成构造函数默认值就是：$\alpha = 0$（false）、$\mathbf{d} = \mathbf{0}$、$\varepsilon = 85$、
$g = 5$、$n = 1$，以及处于静息的五种介质（§4）。

这个向量里有两个承重的结构性决定：

- **炎症不是存储的分量。** 它是 $J(\mathbf{m})$，每次读取时由五种介质**算出来**的加权和（§4）。
  这正是水杨苷与地塞米松得以不同的原因：它们作用于不同的介质，而炎症指数是结果，不是它们共同去写的
  一个变量。
- **$\varepsilon$ 是 $\mathbf{d}$ 的兄弟，不是成员。** 药是身体正在携带、正在清除的东西；酶指数是
  一条清除通路跑得多快。CYP3A4 是香柠檬素的纯函数（§14），所以它不是一个有自己生命的独立量。

## 3. 参考范围与偏离函数

每种矿物都带着一份真实血检报告会给出的那些阈值：

$$\min \;<\; \ell_{\text{sev}} \;<\; \ell \;<\; x_n \;<\; u \;<\; u_{\text{sev}} \;<\; \max$$

其中 $\ell, u$ 是安全带边界，$\ell_{\text{sev}}, u_{\text{sev}}$ 是重度边界。四个区间依次是：
**重度**、**轻度**、**健康**、**轻度**、**重度**。

| 矿物 | 符号 | 单位 | $x_n$ | $\ell$ | $u$ | $\ell_{\text{sev}}$ | $u_{\text{sev}}$ | $\min$ | $\max$ |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 钠 Sodium | $\mathrm{Na}$ | mmol/L | 140 | 135 | 145 | 125 | 150 | 100 | 190 |
| 钾 Potassium | $\mathrm{K}$ | mmol/L | 4.2 | 3.5 | 5.0 | 3.0 | 6.0 | 1.5 | 9 |
| 镁 Magnesium | $\mathrm{Mg}$ | mmol/L | 0.85 | 0.70 | 1.00 | 0.50 | 1.50 | 0.2 | 3 |
| 氯 Chloride | $\mathrm{Cl}$ | mmol/L | 101 | 96 | 106 | 90 | 115 | 70 | 140 |
| 钙 Calcium | $\mathrm{Ca}$ | mmol/L | 2.35 | 2.10 | 2.60 | 1.80 | 3.00 | 1 | 4 |
| 碘 Iodine | $I$ | µmol/L | 0.50 | 0.25 | 0.80 | 0.20 | 1.20 | 0.05 | 2 |
| 维生素C Vitamin C | $A$ | µmol/L | 60.0 | 40.0 | 80.0 | 15.0 | 120.0 | 0 | 150 |

下游大部分工作由两个导出函数完成。绝对偏离是**到安全带之外的距离**，在带内为零：

$$d(x) = \begin{cases} \ell - x, & x < \ell \\[2pt] 0, & \ell \le x \le u \\[2pt] x - u, & x > u \end{cases}$$

而**相对**偏离把这段距离表达成该矿物自身正常值的分数：

$$\rho(x) = \frac{d(x)}{x_n}$$

$d$ 用的是矿物自己的单位。除以 $x_n$ 是不同矿物之间的偏离**可以相互比较**的唯一原因：**$0.2$ 对钠
来说不算什么，对碘却是灾难**。凡是要给矿物排名或合并的地方——最差失衡读数、"最严重偏差"方向——
用的都是 $\rho$。

$\mathrm{isSevere}$ 是 $x < \ell_{\text{sev}}$ 或 $x > u_{\text{sev}}$；方向符号是
$\operatorname{sgn}(x - x_n)$ 在参考带上的取值；饱和压到 $[\min, \max]$。

## 4. 炎症：合成指数

$$J(\mathbf{m}) = \mathrm{clamp}\Big(0.15\,H + 0.20\,P + 0.15\,L + 0.35\,C + 0.15\,B,\; 0,\; 100\Big)$$

权重之和正好是 $1$：

$$\sum_i w_i = 0.15 + 0.20 + 0.15 + 0.35 + 0.15 = 1.00,$$

其中细胞因子占比最大（$0.35$），因为它是全身性的驱动者。由此带来的结果是：$J$ 与介质浓度本身处在
同一个 $0..100$ 刻度上，所以一个每种介质都是 $25$ 的身体读出 $25$。

静息集被选为这个映射的不动点：

| 介质 | $w_i$ | 静息 | 贡献 $w_i m_i$ |
| --- | --- | --- | --- |
| 组胺 histamine | 0.15 | 25 | 3.75 |
| 前列腺素 prostaglandin | 0.20 | 30 | 6.00 |
| 白三烯 leukotriene | 0.15 | 30 | 4.50 |
| 细胞因子 cytokine | 0.35 | 20 | 7.00 |
| 缓激肽 bradykinin | 0.15 | 25 | 3.75 |
| **合计** | **1.00** | | **25.00** |

所以静息向量给出的 $J = 25$ 正好落在安全带 $20..30$ 的中点：

$$J(\mathbf{m}_{\text{静息}}) = \texttt{BASELINE\_INFLAMMATION} = 25.$$

这不是一个需要手工维护的巧合：它就是静息集的定义，只改权重或只改静息值都会挪动基线。

建立在炎症指数上的常数：

| 常数 | 值 | 含义 |
| --- | --- | --- |
| `SAFE_INFLAMMATION_LOW` / `HIGH` | 20 / 30 | 健康带 |
| `BASELINE_INFLAMMATION` | 25 | 上面的不动点 |
| `IMMUNOSUPPRESSION_THRESHOLD` | 12 | 等于或低于它，免疫已经放弃 |
| `IMMUNE_STORM_THRESHOLD` | 75 | 等于或高于它，反应本身开始伤害宿主 |
| `IMMUNE_SHAKE_ONSET` | 75 | 同一个数；见 §15.3 |

## 5. 免疫能力

当前的炎症到底有多能打病原体，取值 $[0, 1]$：

$$K(J) = \exp\!\left(-\frac{\delta(J)^2}{2\,\sigma(J)^2}\right) \cdot \mathrm{clamp}\!\left(\frac{J}{12},\, 0,\, 1\right)$$

其中平台相对距离与分段宽度为

$$\delta(J) = \begin{cases} J - 20, & J < 20 \\[2pt] 0, & 20 \le J \le 40 \\[2pt] J - 40, & J > 40 \end{cases}
\qquad
\sigma(J) = \begin{cases} 10, & J < 20 \quad (\texttt{COMPETENCE\_SIGMA\_LOW}) \\[2pt] 15, & J \ge 20 \quad (\texttt{COMPETENCE\_SIGMA}) \end{cases}$$

这是一条**半高斯平台**：在 $20 \le J \le 40$ 上 $K = 1$ 精确成立，两侧都掉下去，再乘一条在 $J = 0$
时归零的线性斜坡 $J/12$。这种不对称是刻意的，也正是整条函数的意义所在：

| $J$ | 钟形 | 斜坡 | $K$ | 读法 |
| --- | --- | --- | --- | --- |
| 0 | 0.135 | 0.00 | **0.000** | 免疫抑制：完全没有防御 |
| 6 | 0.375 | 0.50 | **0.188** | |
| 12 | 0.726 | 1.00 | **0.726** | 免疫抑制阈值 |
| 20–40 | 1.000 | 1.00 | **1.000** | 平台期：健康 |
| 75 | 0.066 | 1.00 | **0.066** | 风暴跟什么都没有差不多没用 |
| 100 | 0.022 | 1.00 | **0.022** | |

两端失败的原因不同，而这条曲线把这一点说了出来。低于 $20$ 时免疫系统**反应不足**——所以 $\sigma = 10$
这个更紧的下降——而 $J/12$ 斜坡把它压到零，所以一个被药物过量压成免疫抑制的身体什么都清不掉。
高于 $40$ 时它**反应过度**：失调、自己打自己，越往上清得越差，用的是更宽的 $\sigma = 15$。

由此产生了模型的核心张力：**炎症太少和太多都会让感染长起来**，而管用的那个带很窄。这就是水杨苷和
地塞米松构成一个**决策**而不是一个万能键的原因——它们压低反应，这在反应高于平台期时是好事，而一旦
压制把反应推到平台期以下，就变成了主动的伤害。

## 6. 介质动力学

每刻，每种介质向自己的目标走一步 `approach`（§1.3）。这些目标共享一个共同结构：一个被过量缩放的
基线项，加上一个由病原体驱动的反应项。

### 6.1 病原体刺激量

一个标量把病原体载量换算成免疫反应的强度。它是分段的，共三段：

$$S(\lambda, \alpha) = \begin{cases}
0, & \alpha = 0,\; \lambda \le 20 \\[4pt]
0.18\,\dfrac{\lambda}{20}, & \alpha = 1,\; \lambda \le 20 \\[8pt]
\mathrm{clamp}\!\left(\dfrac{\lambda - 20}{55 - 20},\, 0,\, 1\right), & 20 < \lambda \le 55 \\[8pt]
1 + 2.5\,\mathrm{clamp}\!\left(\dfrac{\lambda - 55}{100 - 55},\, 0,\, 1\right), & \lambda > 55
\end{cases}$$

| 载量 | 条件 | $S$ |
| --- | --- | --- |
| $0\text{–}20$ | 免疫尚未启动 | $0$——身体还没察觉 |
| $0\text{–}20$ | 免疫已启动 | $0.18\,\lambda/20$——最高 $0.18$ |
| $20\text{–}55$ | | $(\lambda-20)/35$，从 $0$ 升到 $1$ |
| $55\text{–}100$ | | $1 + 2.5(\lambda-55)/45$，从 $1$ 升到 $3.5$ |

有两点值得直说。

第一段是一个**死区**：在启动载量以下、免疫尚未启动时，反应正好是零。所以一场永远突不破 $20$ 的感染
从来不会激起任何反应——这就是为什么 `IMMUNITY_ACTIVATION_LOAD` $= 20$ 是决定一顿饭会不会让玩家生病的
那个数。

第二点，即 $55$ 以上，是**风暴区**：反应不再与载量成正比，而是升到它的 $3.5$ 倍，所以一场重症产生的
反应比线性大好几倍。正是它把细胞因子顶上去，并通过细胞因子带动发热与风暴症状。

> **一个值得知道的间断点。** 在免疫已启动、载量正好等于 $20$ 时，走的是第二个分支，
> $S = (20/20)\cdot 0.18 = 0.18$。一刻之后载量到 $20.001$，第三个条件不成立，值掉到
> $(20.001-20)/35 \approx 2.86\times10^{-5}$。所以当载量**涨过 $20$** 时，刺激量会**断崖式下跌**
> ——一刻之内从 $0.18$ 掉到几乎为零——而当载量回落时又跳回 $0.18$：
>
> $$\lim_{\lambda \to 20^-} S = 0.18, \qquad \lim_{\lambda \to 20^+} S \approx 0 .$$
>
> 这是分段函数里一道真实的接缝，不是读错了，而且它只在一种很窄的情况下可见：免疫已经启动、且感染
> 正好卡在启动载量上。
>
> 方向对玩家看到的东西很重要。因为下跌发生在载量**上升**时，那个承诺点是感染跨过 $20$ 的瞬间：
> $20$ 以下反应已经以 $0.18$ 全部就位，而一跨过去，这份反应就**崩掉**，只能沿着 $20 \to 55$ 的斜坡
> 从零重建。所以对一个免疫已经启动的身体来说，就介质而言，待在 $20$ 下面比待在 $20$ 上面更好。

### 6.2 药物抑制与过量

水杨苷和地塞米松都在压制，但它们不可互换，而算术就是原因。先把各自写成其有效浓度的饱和倍数：

$$u_s = \mathrm{clamp}\!\left(\frac{[\text{水杨苷}]}{E_s},\, 0,\, 1.5\right), \qquad
u_d = \mathrm{clamp}\!\left(\frac{[\text{地塞米松}]}{E_d},\, 0,\, 1.5\right)$$

其中 $E_s = E_d = 1$（`SALICIN_EFFECTIVE`、`DEXAMETHASONE_EFFECTIVE`），上限
$1.5$（`DRUG_MAX_SUPPRESSION`）。由它们得到三个导出量：

$$f = \max\big(\min(u_s, 1),\; \min(u_d, 1)\big) \qquad\text{（"对抗"项）}$$

$$D = \max(1 - 0.88 f,\; 0.05) \qquad\text{（抑制）}$$

$$O = \max(u_s - 1, 0) + \max(u_d - 1, 0), \qquad
\beta = \max(1 - 1.8\,O,\; 0) \qquad\text{（过量、基线缩放）}$$

这里编码了三个设计决定：

- **$f$ 取最大值，不是求和。** 联用比任一个单独用压得更多（因为两者在下面还有各自不同的额外效果），
  但它们不会叠加成更强的**通用**压制。任一药物达到或超过有效浓度时 $f = 1$，
  $D = 1 - 0.88 = 0.12$：砍掉 $88\%$。
- **有一个地板。** $D \ge 0.05$，所以不管给多少，病原体驱动的反应都不可能被砍到零。
- **过量打的是基线。** 超过有效浓度后，**静息**水平被压下去，每单位超出压 $1.8$：到上限时
  （水杨苷 $3$、地塞米松 $2$）两个抑制值都到 $1.5$，于是 $O = 1.0$、$\beta = 0$。于是静息的介质
  全部瞄准零，炎症塌进个位数——而这正是 $K(J)$ 的斜坡咬下来的地方，也是为什么过量会让感染更严重。

### 6.3 五个目标

$$\begin{aligned}
C^* &= 20\,\beta + 100\,S\,D\,\big(1 - 0.4\min(u_d,1)\big) \\[4pt]
H^* &= 25\,\beta + 45\,S\,D \\[4pt]
B^* &= 25\,\beta + 60\,S\,D \\[4pt]
P^* &= 20\,\beta + \big(0.5\,C + 25\,S\big)\,D\,\big(1 - 0.5\min(u_s,1)\big) \\[4pt]
L^* &= 20\,\beta + \big(0.5\,C + 20\,S\big)\,D\,\big(1 - 0.4\min(u_d,1)\big)
\end{aligned}$$

那些 `BASE` 常数**并不**就是静息集的复制，而这个差别是模型里最容易看漏的一段算术：

| 介质 | $B_i$（`BASE`） | 静息 | 差 | 来自哪里 |
| --- | --- | --- | --- | --- |
| 组胺 | 25 | 25 | 0 | - |
| 缓激肽 | 25 | 25 | 0 | - |
| 细胞因子 | 20 | 20 | 0 | - |
| 前列腺素 | **20** | **30** | $-10$ | $+\,0.5\,C$ |
| 白三烯 | **20** | **30** | $-10$ | $+\,0.5\,C$ |

前列腺素与白三烯各自的写法都比身体该待的位置**低十点**，而那 $10$ 点的差距由 $0.5\,C$ 这一项补上。
静息时 $C = 20$，所以

$$B_P + 0.5\,C = 20 + 0.5 \times 20 = 30 = P_{\text{静息}},$$

这就是为什么即使五个基准中有两个与静息集不一致，静息集仍然是不动点。而这也不是数字上的巧合——那两个
耦合常数满足

$$\texttt{PROSTAGLANDIN\_FROM\_CYTOKINE} = \texttt{LEUKOTRIENE\_FROM\_CYTOKINE} = 0.5
= \frac{P_{\text{静息}} - B_P}{C_{\text{静息}}} = \frac{30 - 20}{20}.$$

只改静息水平或只改那两个基准之一，身体就不再停在炎症 $25$ 上了。

所以没有病原体（$S = 0$）、也没有过量（$\beta = 1$）时，每种介质都瞄准自己的静息值，系统静静停在
$J = 25$。

四个结构性要点：

- **细胞因子先算，并喂给另外两个。** 前列腺素与白三烯各取 $0.5\,C$，代表细胞因子信号下游被诱导出来
  的 COX-2 与 5-脂氧合酶。这就是代码里目标必须按这个顺序排列的原因——用到的 $C$ 是**刚刚 approach
  过**的新值，不是上一刻的。
- **药物专属的额外效果是乘在反应项上的减因子，不是乘在基线上的。** 地塞米松把细胞因子反应再砍
  $40\%$、白三烯反应再砍 $40\%$；水杨苷把前列腺素反应砍 $50\%$。正是这个区别让它们成为不同的药：
  **水杨苷是退烧药**（前列腺素才是抬高调定点的东西，§8），**地塞米松是广谱免疫抑制剂**。
- **那些额外因子乘的是 $S$，所以过量必须通过 $\beta$ 起作用。** 给一个已经是零的项乘系数毫无作用。
- **反应系数的大小顺序是** $100 > 60 > 45 > 25 > 20$，依次为细胞因子、缓激肽、组胺、前列腺素、
  白三烯，所以风暴的炎症由细胞因子主导，而它同时拿着 $0.35$ 的权重。两者从构造上就互相放大。

随后这五项各走一步 `approach`，`MEDIATOR_APPROACH` $= 0.002$，时间常数 **$500$ 刻（$25$ 秒）**。

## 7. 病原体动力学

细菌与病毒分开、但以完全相同的方式跟踪；只有压制它们各自的药不同。两者都走
`stepTargetedPathogen`。

### 7.1 增长与清除

增长是**逻辑斯蒂**的，速率 $r_g$，环境容纳量 $\Lambda = 100$：

$$G(\lambda) = r_g\,\lambda\left(1 - \frac{\lambda}{\Lambda}\right), \qquad r_g = 0.0004
\quad(\texttt{GROWTH\_RATE})$$

在 $\lambda = 50$ 时每刻是 $0.0004 \times 50 \times 0.5 = 0.01$，也就是每 $100$ 刻约涨上限的
$1\%$。$G$ 在区间中段最大、两端归零，正是它让一场感染既不会在很小时停滞，也不会在很大时失控。

清除有**两项**，它们各自的作用不同：

$$X(\lambda) = \begin{cases}
G(\lambda)\,K + r_c\,K, & \alpha = 1 \;\text{或}\; \lambda > 20 \\[4pt]
0, & \text{其它}
\end{cases}
\qquad
r_c = \frac{20}{2 \times 24\,000} = \frac{1}{2400} \approx 4.167\times10^{-4}
\quad(\texttt{CLEARANCE\_BASE\_RATE})$$

- $G(\lambda)\,K$——与"有多少"成正比的清除，形状与增长**相同**。这一项单独在 $K = 1$ 时正好抵消
  增长，把载量按平。
- $r_c K$——一个**常数**项，它才是真正把载量压到零的东西。满能力时它清掉 $20$ 的载量正好用
  **$2$ 个游戏日**。

更新式是

$$\lambda' = \mathrm{clamp}\big(\lambda + G(\lambda) - X(\lambda),\; 0,\; \Lambda\big).$$

在启动载量以下，清除被**完全关掉**——除非免疫已经启动。这就是 §6.1 里那个死区，从另一侧看。

### 7.2 药物压制

每种药的两个阈值是 $s = 1.5$（`SLOW`）与 $q = 3.0$（`SUPPRESS`）；黄连素打细菌，甘草酸打病毒。
记 $\upsilon$ 为药物浓度，并记它在中段里深入了多少：

$$\sigma = \mathrm{clamp}\!\left(\frac{\upsilon - s}{q - s},\, 0,\, 1\right)$$

于是

$$\lambda' = \begin{cases}
\mathrm{clamp}\Big(\lambda - X - r_q\dfrac{\upsilon}{q},\; 0,\; \Lambda\Big), & \upsilon \ge q \\[10pt]
\mathrm{clamp}\Big(\lambda + G\,(1 - 0.75\,\sigma) - X,\; 0,\; \Lambda\Big), & s < \upsilon < q \\[8pt]
\mathrm{clamp}\big(\lambda + G - X,\; 0,\; \Lambda\big), & \upsilon \le s
\end{cases}$$

其中被压制时的清除速率是

$$r_q = \frac{100}{1.5 \times 24\,000} \approx 2.78\times10^{-3}
\quad(\texttt{DRUG\_SUPPRESS\_CLEARANCE\_RATE}).$$

| 浓度 | 行为 |
| --- | --- |
| $\le 1.5$ | 未处理：逻辑斯蒂增长对抗免疫清除 |
| $1.5\text{–}3.0$ | 增长最多被压掉 **$75\%$**，让免疫得以压过它 |
| $\ge 3.0$ | **复制直接停止**——求和里的 $+G$ 项没了——并额外加上 $r_q\,\upsilon/q$ 的清除 |

注意这个结构性差别：中间分支里药**缩放增长项**，顶部分支里药把它**换成了**一个清除项。所以 $q$ 是
一个货真价实的临床阈值——过了它感染只能往下走——而达到它远比逼近它值钱。

### 7.3 免疫启动的迟滞

免疫在超过启动载量时锁上，并一直保持到病原体基本消失：

$$\alpha' = \begin{cases}
\lambda > 0.0001, & \alpha = 1 \\[4pt]
\lambda > 20, & \alpha = 0
\end{cases}$$

这是**迟滞**，它存在的目的是让 $S$ 的死区不会来回抖。一个已经启动免疫的身体会一路保持到载量
$0.0001$；一个还没启动的身体需要载量超过 $20$ 才开始。没有这个锁存，一场卡在 $\lambda = 20$ 的感染
会让反应在相邻两刻之间反复开关。

## 8. 体温调节

### 8.1 目标温度

发热项由**高于静息**的前列腺素驱动：

$$P_{\text{exc}} = \max(P - 30,\, 0), \qquad \Phi_{\text{raw}} = 0.05\,P_{\text{exc}}
\quad(\texttt{FEVER\_PER\_PROSTAGLANDIN})$$

而它**依载量封顶**，分界是 `IMMUNE_STRESS_LOAD` $= 55$：

$$\Phi = \begin{cases}
\min(\Phi_{\text{raw}},\; 2.5), & \lambda \le 55 \\[4pt]
\min(\Phi_{\text{raw}},\; 4.0), & \lambda > 55
\end{cases}$$

其中 $2.5 = $ `FEVER_NORMAL_IMMUNE_MAX` $- 37$，$4.0 = $ `FEVER_MAX`。所以普通感染最高到
$39.5$ °C，只有过了 $55$，封顶才抬到 $41.0$ °C：无论一场普通感染造出多少前列腺素，都够不到高烧
——高烧需要一场风暴。

调定点是六项独立贡献之和：

$$\Theta^* = \mathrm{clamp}\Big(37 + \Phi + \pi + \Delta_{\text{thy}}(I) + \Phi_{\text{anti}} + \Phi_{\text{psi}}
+0.6\,(\Theta_{\text{amb}} - 37),\; 30,\; 42\Big)$$

六项贡献，**全部相加、全部独立**。这是模型关于"体温升高的不同原因不能互相替代"最清楚的表述——
发烧时吃曼德拉草比任何单独一个都更糟，而常数是**强制**了这一点，不只是允许它。

| 项 | 来源 | 范围 | 水杨苷能影响吗？ |
| --- | --- | --- | --- |
| $\Phi$ | 高于静息的前列腺素 | $0 \to +2.5$，风暴中 $+4.0$ | **能**——它是前列腺素项 |
| $\pi$ | 注入（诊断命令） | $-6 \to +6$ | 不能 |
| $\Delta_{\text{thy}}$ | 碘超出其范围 | $-0.8 \to +0.8$ | 不能 |
| $\Phi_{\text{anti}}$ | 东莨菪碱 + 阿托品 | $0 \to +4.0$ | 不能 |
| $\Phi_{\text{psi}}$ | 超过风暴阶段的裸盖菇素醇 | $0 \to +4.0$ | 不能 |
| $0.6(\Theta_{\text{amb}} - 37)$ | 环境，经体温调节 | 见 §8.2 | 不能 |

`FEVER_PER_PROSTAGLANDIN` $= 0.05$ 意味着静息的 $30$ 点前列腺素贡献为零（这一项是相对静息
**之上**测量的），而静息之上每 $20$ 点加 $1$ °C。

**甲状腺项。** 注意除的是 $x_n = 0.5$，不是任何区间的宽度：

$$\Delta_{\text{thy}}(I) = \mathrm{clamp}\Big(2\,\delta_I,\; -0.8,\; +0.8\Big),
\qquad
\delta_I = \begin{cases}
\dfrac{I - 0.25}{0.5}, & I < 0.25 \\[8pt]
\dfrac{I - 0.80}{0.5}, & I > 0.80 \\[8pt]
0, & \text{其它}
\end{cases}$$

其中 $2 = $ `THYROID_SHIFT_PER_RELATIVE`，$0.8 = $ `THYROID_SHIFT_MAX`。因为这个偏移是相对该矿物
自身的正常值表达的，它在被缩放之前是一个无量纲的分数。在硬地板处（$I = 0.05$）原始 delta 是
$(0.05-0.25)/0.5 = -0.4$，给出 $-0.8$ °C——上限正好在碘刻度的最低端被触到：

$$2 \times (-0.4) = -0.8 = -\texttt{THYROID\_SHIFT\_MAX}.$$

**两种药物发热是阶梯，不是曲线。** 记 $\upsilon_{\text{anti}} = $ 东莨菪碱 $+$ 阿托品：

$$\Phi_{\text{anti}} = \begin{cases}
0, & \upsilon_{\text{anti}} < 1.5 \\[4pt]
+1.0, & 1.5 \le \upsilon_{\text{anti}} < 2.5 \\[4pt]
+2.5, & 2.5 \le \upsilon_{\text{anti}} < 4.0 \\[4pt]
+4.0, & \upsilon_{\text{anti}} \ge 4.0
\end{cases}
\qquad\Longrightarrow\qquad
\Theta^* = 37,\; 38.0,\; 39.5,\; 41.0
$$

再记 $\psi$ 为裸盖菇素醇：

$$\Phi_{\text{psi}} = \begin{cases}
0, & \psi \le 5.0 \\[4pt]
+2.0, & 5.0 < \psi < 7.0 \\[4pt]
+4.0, & \psi \ge 7.0
\end{cases}
\qquad\Longrightarrow\qquad
\Theta^* = 37,\; 39.0,\; 41.0$$

两者都是**调定点偏移而不是发热**，代码注释明确说明两者都不经过前列腺素——所以水杨苷对它们毫无作用。
阿托品过量和感染发热是相加的。

### 8.2 趋近与环境链

体温按 `approach` 映射趋近调定点，`TEMPERATURE_APPROACH` $= 0.0004$：

$$\Theta' = \mathrm{clamp}\Big(\Theta + (\Theta^* - \Theta)\cdot 0.0004,\; 30,\; 42\Big)$$

时间常数 **$2\,500$ 刻**（两分多钟游戏时间）。所以身体需要好几分钟才能到达一个新调定点，而不是瞬间
——这正是让发热读起来像一场正在发展的病的原因。

交给模型的环境温度本身也是模型算出来的，来自世界的生物群系温度 $T_{\text{biome}}$ 与几个标志位。
先算原始拉力：

$$\Pi = 2.0\,(T_{\text{biome}} - 0.8)
\;-\; 2.5\,\mathbb{1}[\text{潮湿}]
\;-\; 4.0\,\mathbb{1}[\text{细雪}]
\;+\; \begin{cases} 6.0, & \text{岩浆} \\ 4.0, & \text{火} \\ 0, & \text{其它} \end{cases}$$

其中 $0.8 = $ `TEMPERATE_BIOME`，$2.0 = $ `BIOME_PULL`。然后**热中性带**把前两度免费扣掉：

$$\Pi_{\text{eff}} = \begin{cases}
\Pi - 2.0, & \Pi > 2.0 \\[4pt]
\Pi + 2.0, & \Pi < -2.0 \\[4pt]
0, & \text{其它}
\end{cases}
\qquad
\Theta_{\text{amb}} = \mathrm{clamp}(37 + \Pi_{\text{eff}},\; 30,\; 42)$$

这个带才是关键：前 $2$ °C 的拉力完全不花代价。温带生物群系是 $0.8$，所以约 $2.0$ 的沙漠是
$(2.0-0.8)\times 2 = 2.4$ 的拉力，扣掉热中性带只剩 $0.4$ °C 的**环境**温度——而其中又只有 $60\%$
能到达身体。这就是为什么模型的"热"这一侧几乎完全由发热而不是天气驱动，也是为什么走过针叶林不算一次
医疗事件。冷的那一侧杠杆大得多：细雪是 $-4.0$ 的拉力。

### 8.3 致热原

注入的致热原**就是**一个调定点偏移，而它只在它所驱动的发热真正发展起来之后才开始清除：

$$\pi' = \begin{cases}
0, & \pi = 0 \\[4pt]
\pi, & \lvert \Theta - \Theta^* \rvert \ge 0.2 \\[4pt]
\max(\pi - r_\pi,\, 0), & \pi > 0 \\[4pt]
\min(\pi + r_\pi,\, 0), & \pi < 0
\end{cases}
\qquad
r_\pi = \frac{6}{24\,000} = 2.5\times10^{-4}
\quad(\texttt{PYROGEN\_DECAY\_PER\_TICK})$$

`PYROGEN_SETTLED` $= 0.2$ °C。没有这个等待，偏移会在身体还在往上爬的时候就撤掉，发热的峰值就到不了
要求的高度——以前要 $39.5$ 只到 $38.8$。有了它，峰值正好落在要求上。衰减是线性的，对正负偏移对称
（负致热原就是退烧）。

`induceFever` 把整件事反过来解，并替那个沉降容差买单，好让峰值精确。给定要求的绝对温度
$\Theta_{\text{req}}$：

$$\Theta_0 = \Theta^*\big|_{\pi = 0}, \qquad
\pi_{\text{naive}} = \Theta_{\text{req}} - \Theta_0, \qquad
\pi_{\text{needed}} = \pi_{\text{naive}} + 0.2\,\operatorname{sgn}(\pi_{\text{naive}})$$

$$\pi \leftarrow \mathrm{clamp}(\pi_{\text{needed}},\; -6,\; +6) \quad(\texttt{PYROGEN\_CAP})$$

感染从不走这条路径：它的发热来自前列腺素，所以 $\pi$ 保持为零，`stepPyrogen` 立刻返回。

## 9. 水分

记

$$w^+ = \max(w - 100,\, 0)$$

为高出正常的那部分。每刻的流失是基础流失（被水过多和两种电解质过高放大）加上出汗：

$$\ell = r_w\big(1 + 0.01\,w^+\big)\,\mu_{\mathrm{Na}}\,\mu_{\mathrm{Ca}} \;+\; \sigma(\Delta\Theta)$$

$$r_w = \frac{100}{5 \times 24\,000}, \qquad
\mu_{\mathrm{Na}} = \begin{cases} 1.3, & \mathrm{Na} > 145 \\ 1, & \text{其它}\end{cases}, \qquad
\mu_{\mathrm{Ca}} = \begin{cases} 1.2, & \mathrm{Ca} > 2.60 \\ 1, & \text{其它}\end{cases}$$

$$w' = \mathrm{clamp}(w - \ell,\; 0,\; 200)$$

出汗项是一条**带死区的下开口抛物线**：先为负，在 $\Delta\Theta = 1.25$ 处过零，然后转正并加速。

$$\Delta\Theta = \max(\Theta - 37,\, 0), \qquad
\sigma(\Delta) = \begin{cases}
\max\big(a\Delta + b\Delta^2,\; 0\big), & \Delta > 1.25 \\[4pt]
0, & \Delta \le 1.25
\end{cases}$$

$$a = -\frac{1}{3360} \quad(\texttt{SWEAT\_A}), \qquad b = \frac{1}{4200} \quad(\texttt{SWEAT\_B})$$

它被写成二次式是因为两个校准点要求如此，而那两个点给出两个方程，正好定下两个系数：

| $\Delta\Theta$ | 核心体温 | 出汗 $\sigma$ | 每刻总流失 | $100$ 水够用 |
| --- | --- | --- | --- | --- |
| $\le 1.25$ | $\le 38.25$ | $0$ | $1/1200$ | **5 天** |
| $2$ | $39.0$ | $1/2800$ | $1/840$ | **3.5 天** |
| $3$ | $40.0$ | $1/800$ | $1/480$ | **2.0 天** |

这条抛物线的根值得核一下，因为正是它让那个判断条件恰如其分：

$$a + b\Delta = 0 \;\Longrightarrow\; \Delta = -\frac{a}{b} = \frac{4200}{3360} = 1.25 .$$

同一条抛物线在 $1.25$ 以下是**负的**，所以那句 $\Delta > 1.25$ 不是图方便，它是承重的：没有它，
$38.25$ °C 以下的发热会让身体**涨水**。

两种电解质过高会乘算流失（高钠血症与高钙血症都会导致口渴与尿量增加），而水过多在刻度顶端会把基础
速率加到**两倍**，因为那里 $w^+$ 到 $100$：

$$1 + 0.01 \times 100 = 2 .$$

## 10. 电解质

五种电解质各自独立地走同一个函数：

$$x' = \mathrm{clamp}\Big(x + (x_n - x)\,h \;-\; L\,\varepsilon_x \cdot \frac{x}{x_n}\cdot x_n,\;\; x_{\min},\; x_{\max}\Big)$$

其中 $h = 0.00005$（`ELECTROLYTE_HOMEOSTASIS`）。两股力量，结构上不同：

- **稳态**——一个朝 $x_n$ 的比例控制器，时间常数 $1/h = 20\,000$ 刻（不到一个游戏日）。正是它让
  每种电解质停在一个稳态而不是漂到极端：不管 $L$ 做什么，这一项都往回拉。
- **排泄**——第三项，源码把它写成 $L\,\varepsilon_x\,(x/x_n)\,x_n$。因为浓度因子与正常值正好约掉，
  这个乘积其实是

  $$L\,\varepsilon_x \cdot \frac{x}{x_n}\cdot x_n = L\,\varepsilon_x\,x,$$

  所以这一项**与数值本身成正比**。肾脏处理的滤过负荷是血浓度乘以清除体积，所以高的电解质比低的排得
  快，同样的 $L$ 清空一个满的储备比清空一个快见底的储备要快。在 $x = x_n$ 时浓度因子正好是 $1$，
  所以两个健康值之间的漏出就是基准漏出 $L\varepsilon_x x_n$。（源码写成那个长式，是因为**读法**
  ——浓度乘以正常值——才是生理学；约掉只是让算术变便宜。）

每种矿物的相对尿损失，正是"盐水补盐而不是补一切"的原因：

| 矿物 | $\varepsilon_x$ |
| --- | --- |
| 钠 Sodium | 1.0 |
| 氯 Chloride | 1.0 |
| 钾 Potassium | 0.7 |
| 镁 Magnesium | 0.4 |
| 钙 Calcium | 0.4 |

共用的 $L$ 是两种失水机制之和，两者从构造上都是无量纲的：

$$L = \underbrace{9\times10^{-6}\,\min\!\left(\frac{w^+}{100},\, 1\right)}_{\text{冲刷}}
\;+\; \underbrace{\begin{cases} 2\times10^{-6}\,\Delta\Theta, & \Delta\Theta > 1.25 \\ 0, & \Delta\Theta \le 1.25 \end{cases}}_{\text{出汗}}$$

`mineralFlush` 在水量刻度顶端饱和；`mineralSweat` 复用水出汗项的同一个 $1.25$ °C 死区，所以身体
不会在不出汗的时候流失盐分。一切都是某个矿物**正常浓度**的一个分数，这正是同一段代码既能用在
$140$ mmol/L 的钠上、也能用在 $0.5$ µmol/L 的碘上的原因。

## 11. 微量元素

碘与维生素C被单独处理，因为它们都不被调向某个设定点。身体两者都造不出来，所以没吃进去的就是丢掉的。

### 11.1 碘——一条恒定漏失加一个过量项

$$I' = I - \Big[\big(f_d + 0.7\,L\big)\,x_n^{I} \;+\; c_e \max(I - x_n^{I},\, 0)\Big]$$

$$f_d = \frac{(0.5 - 0.05)/(15 \times 24\,000)}{0.5} = 2.5\times10^{-6}
\quad(\texttt{IODINE\_DRAIN\_FRACTION}), \qquad c_e = 6\times10^{-6}
\quad(\texttt{IODINE\_EXCESS\_CLEARANCE})$$

设计要点是这条漏失是**恒定的**，不是成比例的：

- 日常流失是 $2.5\times10^{-6} \times 0.5 = 1.25\times10^{-6}$ 每刻，所以一个满储备从 $0.50$ 掉到
  硬地板 $0.05$ 正好用 **$15$ 个游戏日**：

  $$\frac{0.50 - 0.05}{1.25\times10^{-6}} = 360\,000 \text{ 刻} = 15 \times 24\,000 .$$

  这是一个精确值而不是渐近值，因为从固定起点出发的恒定流失走的是固定时间。
- **朝 normal 的比例控制器被刻意省略了。** 它恰恰是那个会让储备永远耗不尽的东西，而碘本来就该是一个
  膳食需求，不是白送的加成。
- 过量项是相对**高于 normal 的那部分**写的，不是相对整个数值。一个随数值本身缩放的漏失会弯折这条
  耗尽曲线，而"从正常到地板十五天"是测试和文档都会引用的一个数。

那两个看起来矛盾的常数并不矛盾。日常漏失被放慢到三分之一（$f_d$），而过剩清除**快了三倍**（$c_e$）。
这两个改动朝相反方向拉是刻意的：一个只是勉强够用的身体把碘留得久得多，而一个带着太多碘的身体很快就
甩掉它，两者之间的那个带就是数值稳定下来的地方。

出汗（$0.7L$）在漏失之上又带走一部分碘，这正是长期发热会把一个本来够用的膳食压到参考范围以下的原因。

### 11.2 维生素C——一级消除

$$A' = \mathrm{clamp}\Big(A\,(1 - k_A),\; 0,\; 150\Big)$$

其中速率是从半衰期推导出来的，不是反过来：

$$k_A = \frac{\ln 2}{5 \times 24\,000} \approx 5.776\times10^{-6}
\quad(\texttt{VITAMIN\_C\_DECAY\_RATE}), \qquad T_{1/2} = 5 \times 24\,000 \text{ 刻}$$

这是模型里唯一使用**真正的一级（指数）动力学**而不是 §1.3 所述线性形式的地方，而且常数是从半衰期
推导出来的，不是反过来。解 $(1-k_A)^{T_{1/2}} = \tfrac12$ 正好还原出所说的半衰期，这正是让那个标志性
数字精确的原因：$80.0 \to 40.0$ 恰好 $5$ 个游戏日，$40.0 \to 20.0$ 再用 $5$ 天，以此类推——在对数
轴上是直线，在线性轴上不是：

$$\ln A(t) = \ln A(0) - k_A t .$$

注意这与碘的行为相反，碘那边正是**恒定**漏失让它的标志性数字精确。两者都是刻意的。钳制范围是
$[0, 150]$，所以维生素C永远不会变成负数，过剩也是有界的。

## 12. 血糖与胰岛素

### 12.1 胰岛素指数

$$n^*(g) = \begin{cases}
1, & g \le 5 \\[4pt]
1 + 2\,(g - 5), & 5 < g \le 8 \\[4pt]
7 + 4\,(g - 8), & g > 8
\end{cases}$$

两条斜坡相接而不断，这正是 `ELEVATED_INSULIN_TARGET` 存在所要保证的：

$$\texttt{ELEVATED\_INSULIN\_TARGET} = \underbrace{n_{\text{正常}}}_{1} + (\underbrace{8}_{g_{\text{升高}}} - \underbrace{5}_{g_{\text{正常}}}) \times \underbrace{2}_{k_1} = 1 + 3 \times 2 = 7$$

所以第一条斜坡在 $g = 8$ 处正好到 $7$，而那正是第二条斜坡的起点。连续性条件因此是

$$1 + k_1\,(g_e - g_0) = 7 = n^*(g_e^+),$$

第二条斜率是第一条的**两倍**——这就是"过了 $8$，胰腺的反应已经不容置疑"的意思。指数随后以
`INSULIN_APPROACH` $= 0.0005$ 趋近目标：

$$n' = \mathrm{clamp}\Big(n + (n^*(g) - n)\cdot 0.0005,\; 0,\; 60\Big)$$

时间常数 **$2\,000$ 刻**（$100$ 秒），所以胰岛素是滞后于一餐，而不是瞬间跟上一餐。

### 12.2 血糖

$$g' = \mathrm{clamp}\Big(g - \beta(g) - U - V,\; 0,\; 30\Big)$$

三项，它们分开是因为行为不同。

**基础消耗** $\beta$ 分三段，而这个形状正是让血糖成为模型里唯一一个被**花掉**而不是被调节的量的原因：

$$\beta(g) = \begin{cases}
1.5\,y, & g > 5.5 \\[4pt]
y/3, & 3.5 < g \le 5.5 \\[4pt]
\dfrac{y}{3}\cdot\dfrac{g}{3.5}, & g \le 3.5
\end{cases}$$

两个在用速率都是相对一把**标尺**写的，而不是字面量：

$$y = \frac{g_{\text{正常}} - g_{\text{地板}}}{2 \times 24\,000} = \frac{5 - 3.5}{48\,000} = 3.125\times10^{-5}
\quad(\texttt{GLUCOSE\_DECAY\_YARDSTICK})$$

那是模型**最初**校准所用的消耗速率——两个游戏日掉 $1.5$ mmol/L。现在没有任何东西按这个速率燃烧了；
它被保留下来，是为了让两个在用速率之间的关系在重新校准之后依然成立：

$$\underbrace{\frac{y}{3} = 1.0417\times10^{-5}}_{\text{基础}}, \qquad
\underbrace{1.5\,y = 4.6875\times10^{-5}}_{\text{过量}}$$

基础速率是 $y/3$（于是从 $5.0$ 掉到 $3.5$ 的地板现在要**六**天而不是两天），过量速率是
$y \times 1.5$——比模型**最初**的速率快一半，刻意地不比那个已经减慢的速率快一半：

$$\frac{5.0 - 3.5}{y/3} = 144\,000 \text{ 刻} = 6 \text{ 天}, \qquad
\frac{1.5}{1.5y} = 32\,000 \text{ 刻} \approx 1.33 \text{ 天}.$$

这就是为什么在正常带变温和之后，一次血糖尖峰仍然有代价。低于 $3.5$ 时速率随剩余血糖缩放，所以下落
会减速，而不是一路直线冲到零。

**内源胰岛素摄取**与胰岛素高出空腹的量成正比，并且在**参考范围底部被关掉**：

$$U = \begin{cases}
0, & g \le 4 \\[4pt]
\min\big(10^{-4}\max(n - 1,\, 0),\; g - 4\big), & g > 4
\end{cases}$$

**注射的**门冬胰岛素则完全不加刹车：

$$V = 8\times10^{-5}\,\iota \qquad (\texttt{GLUCOSE\_UPTAKE\_PER\_INSULIN\_ASPART})$$

内源项有两道刹车，两道都重要。$\min$ 防止一刻之内冲过 $4.0$ 以下，而那个分支条件保证胰腺永远不会
靠自己把一个身体推进低血糖。**注射的门冬胰岛素两道刹车都没有**——$V$ 是无条件相加的——而这个
不对称正是过量危险的全部原因。

### 12.3 低血糖

$$\text{等级}(g) = \begin{cases}
3, & g < 1.3 \\[4pt]
2, & 1.3 \le g < 1.7 \\[4pt]
1, & 1.7 \le g < 2.0 \\[4pt]
0, & g \ge 2.0
\end{cases}
\qquad
D_{\text{低血糖}}(g) = \begin{cases}
0, & g \ge 1.3 \\[4pt]
1.3 - g, & g < 1.3
\end{cases}$$

| 等级 | 血糖 | 效果 |
| --- | --- | --- |
| 0 | $\ge 2.0$ | 无 |
| 1 | $< 2.0$ | 挖掘疲劳 |
| 2 | $< 1.7$ | 外加虚弱 |
| 3 | $< 1.3$ | 外加魔法伤害 |

伤害随血糖低于阈值多少而缩放，所以最后那一点最疼。它每次效果结算施加一次（§16.1），是模型里除脓毒症
之外唯一一个不需要任何怪物就能杀死玩家的症状。

## 13. 药代动力学

`stepDrugs` 在一刻中最先跑，早于任何读取浓度的东西。除维生素C之外全部使用**线性**形式

$$d' = \max(d - r,\, 0), \qquad r = \frac{C}{T}$$

这意味着一种药的**存活时间**取决于它有多少：在上限时用所述时间清完，在半量时用一半时间。

| 东莨菪碱 Scopolamine | 5 | 24,000（1 天） | $2.083\times10^{-4}$ | 线性 |
| 阿托品 Atropine | 5 | 24,000（1 天） | $2.083\times10^{-4}$ | 线性 |
| 裸盖菇素 Psilocybin | 10 | 12,000（½ 天） | $1.083\times10^{-4}$ | 线性 $\to$ 裸盖菇素醇 |
| 裸盖菇素醇 Psilocin | 10 | 24,000（1 天） | $5.417\times10^{-5}$ | 线性 |

### 13.1 裸盖菇素 → 裸盖菇素醇 的转化链

$$\kappa = \min\Big(\psi_{\text{by}},\; \frac{1.3}{12\,000}\Big), \qquad
\psi_{\text{by}}' = \psi_{\text{by}} - \kappa$$

$$\psi_{\text{cin}}' = \mathrm{clamp}\Big(\psi_{\text{cin}} + \kappa - \frac{1.3}{24\,000},\; 0,\; 10\Big)$$

一次**一比一的前体转化**：从裸盖菇素离开多少，就在同一刻以裸盖菇素醇的形式到达，而裸盖菇素醇同时
在清除。两个速率都以一个蘑菇为单位书写（`PSILOCIN_DOSE` $= 1.3$），这正是让算术可读的原因：

- 裸盖菇素每刻转化 $1.3/12\,000$，所以一次剂量要**半个游戏日**转化完。
- 裸盖菇素醇每刻清除 $1.3/24\,000$——不管浓度多高都是这个**恒定**速率，所以一个蘑菇一天就没了，
  而十个要八天。成比例的速率会让十个跟一个以同样的节奏消失，那不是一次剂量该有的样子。

因为裸盖菇素是两者中较慢的那个，裸盖菇素醇的浓度在**吃下去之后还会再涨一会儿**，尽管一点都没被吞下：
前体在不断给它续上。这正是 $\kappa$ 里那道 $\min$ 的意义——让最后不足一刻的那部分只转化剩下的量。

### 13.2 乙醇

`ETHANOL_CAP` $= 1.0$，且每次饮用都把上限值整个计入，所以这个指数实际上是"一杯酒还留在体内的比例"，
在一个游戏日内清完。它对模型里任何其他量都没有影响——它只是被记录，不是被模拟。

## 14. CYP3A4 与香柠檬素的相互作用

肝脏的酶指数不是一个有自己生命的量。它是**一条关于香柠檬素的曲线**，每刻重新计算，所以它与香柠檬素
之间的分歧永远不会超过"吃下去"到"下一步"之间的那一小刻。这条曲线由五个节点 $(\nu_i, \varepsilon_i)$
定义：

$$(\nu_i, \varepsilon_i) = (0,\, 85),\; (2,\, 60),\; (4,\, 45),\; (7,\, 25),\; (8.5,\, 10)$$

| 香柠檬素 | CYP3A4 | 西柚片数 |
| --- | --- | --- |
| 0 | 85 | 无 |
| 2 | 60 | 2 |
| 4 | 45 | 4 |
| 7 | 25 | 7 |
| $\ge 8.5$ | 10 | 8 片半——**地板** |

节点之间是**平滑阶跃**（smoothstep），不是线性插值。对 $\nu_i \le \nu < \nu_{i+1}$：

$$t = \mathrm{clamp}\!\left(\frac{\nu - \nu_i}{\nu_{i+1} - \nu_i},\, 0,\, 1\right), \qquad
\varepsilon(\nu) = \varepsilon_i + (\varepsilon_{i+1} - \varepsilon_i)\,h(t), \qquad
h(t) = 3t^2 - 2t^3$$

而在最后一个节点之后，对所有 $\nu \ge 8.5$ 都有 $\varepsilon = 10$。

平滑阶跃在**两端斜率都为零**：

$$h'(t) = 6t - 6t^2 = 6t(1 - t) \;\Longrightarrow\; h'(0) = h'(1) = 0,$$

所以每个节点都是平着进、平着出，曲线在两段相接的地方没有折角。线性插值会在每个校准点留一个尖角，
而酶指数被黄连素的代谢连续读取，那些尖角就会表现为"一次剂量能撑多久"的突然变化。每多吃一片都让肝脏
再少一点，而不是一越过某个阈值就全变。

过了最后一个节点活性**保持在 $10$**，这正是让八片半成为抑制作用最深处的那个数——$h$ 定义在一个闭区间
上，下降就此结束，所以它是一段下降的底部，而不是一次跳变的另一侧。

下游实际使用的分数是

$$\phi = \frac{\varepsilon}{85} \quad(\texttt{CYP3A4\_NORMAL}), \qquad
\phi\big|_{\varepsilon = 85} = 1.0, \qquad
\phi\big|_{\varepsilon = 10} = \frac{10}{85} \approx 0.1176$$

所以在没吃过西柚时，黄连素的代谢就是模型一直以来的那个速率。在地板处

$$\text{存活时间倍数} = \frac{1}{\phi} = \frac{85}{10} = 8.5\times$$

而黄连素是唯一一个以这种方式缩放的化合物：

$$d_{\text{黄连素}}' = \max\big(d_{\text{黄连素}} - r_{\text{黄连素}}\,\phi,\; 0\big)$$

**一刻之内的顺序：**香柠檬素先衰减，**然后**酶指数才从剩下的量读出来。一刻是模型最小的步长，所以
"肝脏按这么多西柚所允许的速率清除黄连素"，是由该刻结束时身体实际还带着的香柠檬素决定的。

## 15. 症状量级

这些由 Kotlin 层读取，永远不会写回状态。每一个都是身体的纯函数。

### 15.1 严重度——共用的归一化

$$\mathrm{sev}(\lambda) = \mathrm{clamp}\!\left(\frac{\lambda}{60},\, 0,\, 1\right)$$

在 `SEVERE_LOAD` $= 60$ 处饱和，所以对下面这些量级来说，任何等于或高于 $60$ 的载量都是"最严重就是
这样"。脓毒症伤害是唯一一个过了它还会继续缩放的东西（§15.2）。

### 15.2 脓毒症

$$D_{\text{脓毒症}}(\lambda) = \begin{cases}
0, & \lambda < 60 \\[4pt]
1 + \dfrac{\lambda - 60}{40}, & \lambda \ge 60
\end{cases}$$

| 载量 | 每次结算伤害 |
| --- | --- |
| 59 | 0 |
| 60 | 1.0 |
| 80 | 1.5 |
| 100 | 2.0 |

过阈值之后每 $20$ 点多半点。每次效果结算施加一次（§16.1），所以 $60$ 的载量每两秒花掉**半颗心**，
$100$ 每秒一颗心——分别约 $40$ 秒和 $20$ 秒打光十颗心。魔法伤害，所以盔甲没用：这是病原体，不是一击。

### 15.3 视角摇晃

两个独立的量：**有没有**摇晃，以及**摆多少**。

$$\chi = \min\Big(\;\underbrace{0.2\,\mathbb{1}[\lambda \ge 8]}_{\text{有症状}}
+\underbrace{0.2\,\mathbb{1}[J \ge 75]}_{\text{风暴}}
+0.1\,\mathbb{1}[w > 150]
+0.15\,\mathbb{1}[\mathrm{Mg} < 0.70]
+0.2\,\mathbb{1}[\mathrm{Ca} < 1.80]
+0.1\,\mathbb{1}[I > 1.20]
+\underbrace{0.15\,\lvert T_{\text{th}} \rvert}_{\text{体温}},\;\; 0.85\Big)$$

| 来源 | 贡献 | 为什么玩家看得见 |
| --- | --- | --- |
| 有症状（$\lambda \ge 8$） | $+0.2$ | 病本身 |
| 免疫风暴（$J \ge 75$） | $+0.2$ | 风暴伴随发热，而发热有图标 |
| 水 $> 150$ | $+0.1$ | 过了恶心图标出现的那个点 |
| 镁 $< 0.70$ | $+0.15$ | 神经肌肉兴奋性增高 |
| 钙 $< 1.80$ | $+0.2$ | |
| 碘 $> 1.20$ | $+0.1$ | 甲亢性心悸 |
| 体温应激 | $+0.15 \times \lvert T_{\text{th}} \rvert$ | 牙齿打颤、寒战 |

上限 **$0.85$**，所以没有任何状态会让镜头每一次投骰都摇。源码里写明的设计准则是：**每一项都必须来自
玩家能察觉的东西，而每一个能造成颤抖的来源也都会在屏幕上放一个效果图标**——否则玩家无从判断自己的
视角为什么在动。这就是为什么水过多只在过了恶心阈值之后才算数，以及为什么 $38.5$ 以下的发热完全不计。

免疫项是**阶梯，不是斜坡**：

$$\mathbb{1}[J \ge 75] \quad\text{其中}\quad \texttt{IMMUNE\_SHAKE\_ONSET} = \texttt{IMMUNE\_STORM\_THRESHOLD} = 75$$

在风暴之下，炎症无论爬多高对摇晃概率的贡献都是**零**；到风暴时它一步贡献全部 $+0.2$。这是相对早期
版本（从 $40$ 开始渐入）的一个刻意改动，理由是颤抖是风暴症状，仅此而已——一次普通的免疫反应，以及
通往风暴的过程，都不该表现为颤抖。它同时也把摇晃的**概率**与下面摇晃的**幅度**对齐了，后者的风暴项
一直都恰好在这个点上门控。那 $+0.2$ 是旧版风暴对症状项的加倍，这里保留为**相加而不是相乘**：一个有
症状的身体以前会被风暴把 $0.2$ 加倍成 $0.4$，而免疫项现在在到达风暴的那一刻提供同样的 $+0.2$。所以
风暴摇晃的频率与从前完全一样，而风暴之下的身体根本不会因为炎症而摇晃。

注意当起始点与风暴点重合时，**没有任何可以渐入的区间**——那条斜坡的定义域是 $[75, 75]$，宽度为零
——这就是这个因子是阶梯而不是直线的原因。

幅度是另一个独立的和：

$$A = 0.3 + 0.4\,\mathrm{sev}(\lambda) + 0.3\,\mathbb{1}[J \ge 75]
+0.2\,\mathbb{1}[\mathrm{Ca} < 1.80] + 0.2\,\mathbb{1}[\text{体温应激}]$$

| 条件 | 幅度 |
| --- | --- |
| 安静的身体 | $0.3°$ |
| 严重载量（$\ge 60$） | $0.7°$ |
| 风暴 | $0.6°$ |
| 发冷或发热 | $0.5°$ |
| 严重缺钙 | $0.5°$ |
| **全部同时** | **$1.4°$** |

刻意温和：颤抖要读起来像"生病了"，而不是让游戏变得难玩，所以即使一场严重感染背上风暴和高热，也仍然
远在玩家能正常瞄准的范围之内。

### 15.4 食物消耗与挖掘

$$M_{\text{消耗}} = 1
+0.5\,\mathrm{sev}(\lambda)\,\mathbb{1}[\lambda \ge 8]
+0.5\,\mathbb{1}[J \ge 75]
+0.2\,\mathbb{1}[\text{水过多}]
+0.2\,\mathbb{1}[\mathrm{Cl} > 106]
+0.15\,\mathbb{1}[\mathrm{Mg} < 0.70]
+0.25\,\mathbb{1}[\text{体温应激}]$$

$$P_{\text{挖掘}} = 0.06\,\mathrm{sev}(\lambda)\,\mathbb{1}[\lambda \ge 8]
+0.08\,\mathbb{1}[\text{水过多}]
+0.06\,\mathbb{1}[\mathrm{K} < 3.5]
+0.04\,\mathbb{1}[\mathrm{Ca} < 2.10]$$

注意这两者**不是**按同一种方式缩放的。消耗项是 $0.5 \times \mathrm{sev}$，所以小病代价很小，重病才
吃满那额外的一半；挖掘惩罚是同一个形状上的 $0.06 \times \mathrm{sev}$。其余全是固定相加，不管超出
范围多远都一视同仁——镁在 $0.69$ 和镁在 $0.2$ 值同样那 $0.15$，因为这个症状的成因是**出界**，不是
出界多少。

消耗乘数是一个**围绕 $1$ 的乘数**（"$1$ 就是没毛病"），所以这些项与原版自己的食物消耗以乘法方式复合。
挖掘惩罚则是一个**正的分数**，从挖掘速度里减掉。另外两个饱和辅助函数在别处喂给它们：

$$\text{thermalExhaustion}(T_{\text{th}}) = 0.03\,\lvert T_{\text{th}} \rvert, \qquad
\text{stormExhaustion} = 0.05$$

### 15.5 分级函数

$$T_{\text{th}}(\Theta) = \begin{cases}
+2, & \Theta \ge 40.0 \\[4pt]
+1, & 38.5 \le \Theta < 40.0 \\[4pt]
0, & 36.0 < \Theta < 38.5 \\[4pt]
-1, & 35.0 < \Theta \le 36.0 \\[4pt]
-2, & \Theta \le 35.0
\end{cases}
\qquad
F(\Theta) = \begin{cases}
3, & \Theta \ge 40.0 \\[4pt]
2, & 39.5 \le \Theta < 40.0 \\[4pt]
1, & 38.5 \le \Theta < 39.5 \\[4pt]
0, & \Theta < 38.5
\end{cases}$$

$T_{\text{th}}$ 是**症状**刻度（有符号，两级发热、两级低体温），而 $F$（`feverGrade`）是**指示器**
刻度（无符号，三级发热）。它们刻意不是同一把梯子：$39.5$ 值得告诉玩家，尽管它造成的虚弱并不比
$38.6$ 更重。两者共用同样三个阈值，所以指示器与症状在"发热从哪里开始、在哪里到顶"上永远不会分歧。
`hasPain` 又是另一个，挂在 `PAIN_THRESHOLD` $= 39.5$ 上——疼痛在第二级到来并停在那里，所以一个
$40.5$ 的玩家不会被告知自己正承受三倍的疼痛。

这些分级函数全都是**没有插值的阈值阶梯**，而阈值用的是共用常数，不是重复的字面量：

$$\text{低血糖等级}(g): 3 \to 2 \to 1 \to 0 \text{ 于 } 1.3,\; 1.7,\; 2.0 \quad(\S12.3)$$

$$\text{裸盖菇素醇等级}: 0 \to 1 \to 2 \to 3 \to 4 \text{ 于 } 1.2,\; 1.7,\; 2.5,\; 5.0$$

$$\text{口渴格数}(w) = \left\lfloor \mathrm{clamp}\!\left(\frac{w}{10},\, 0,\, 10\right) \right\rfloor$$

裸盖菇素醇的各阶段是**嵌套**的——$3$ 阶段的幻觉仍然带着描边和变色，因为对应的客户端效果是整件事以
更高强度呈现，而不是在上面叠一层。这些阈值严格递增（$1.2 < 1.7 < 2.5 < 5.0$），比较用的是严格
$>$：

$$\text{裸盖菇素醇等级} = \#\{i : \psi > \theta_i\}, \qquad
\theta = (1.2,\, 1.7,\, 2.5,\, 5.0),$$

所以在 $1.2$ 时等级正好是 $0$、刚过一点才是 $1$——处在描边阈值上的身体还没有描边。

$\text{口渴格数}$ 把 $0..200$ 的水量指数分成 **$10$ 个每格 $10$ 点**，也就是口渴条画的东西；所以
$100$ 水正好是 $10$ 个满格，而这个刻度与 `/aliment` 报告的是同一个。

环境常数 `TEMPERATE_BIOME` $= 0.8$ 是原版对温带生物群系的定义，所以 $0.8$ 的生物群系就是环境刻度的
中性点。

## 16. 一刻之内的运算顺序

`Physiology.tick` 按一个特定顺序跑各步，而这个顺序不是随意的——每一个选择都记在这里，因为改它就会改
模型。

| # | 步骤 | 读取 |
| --- | --- | --- |
| 1 | `stepDrugs` | 药物衰减；香柠檬素先衰减，然后 CYP3A4 从剩下的量读出 |
| 1 | `enzymes` | $= \varepsilon(\text{香柠檬素})$——代谢刚刚用过的那个值 |
| 1 | `stepPyrogen` | 致热原清除，以沉降容差为门控 |
| 1b | `stepInsulin` | 身体自身的胰岛素朝血糖要求的方向移动 |
| 1b | `stepGlucose` | **新**的胰岛素与**新**的门冬胰岛素 |
| 1b | `stepBacteria` / `stepVirus` | **旧**的能力值 |
| 2 | `immuneActive` | 超过启动载量时锁上（迟滞） |
| 3 | `stepMediators` | 五种介质向目标趋近；$K$ 用**旧**炎症，$S$ 用**新**载量 |
| 4 | `stepTemperature` | 读**新**的介质；体温只写一次 |
| 4 | `stepWater` | 这一刻**开始时**的体温 |
| 4 | `stepElectrolytes` | 新的水量（用于冲刷）与新的体温 |
| 4 | `stepTraceElements` | 同前 |

其中四点值得单独说明。

**药物最先。** 所有下游读取浓度的东西都必须看到当前浓度，所以代谢领跑。这也意味着一刻之内吃下的剂量
会被立刻感受到，但已经损失了那一小刻的衰减。

**酶从衰减之后的香柠檬素重新读出**，然后既写进状态、又用于黄连素那一步。所以状态里的 $\varepsilon$
与实际被套用的速率是**由构造保证**一致的，而不是靠两处调用点碰巧问同一个问题。

**血糖读新的胰岛素，但用旧的能力值。** 胰岛素在同一阶段更新，因为它属于同一个子系统；而病原体／
免疫那一步刻意使用在刻开始时算出的能力值，这正是让免疫反应比感染晚一步、而不是瞬时的原因。

**体温只写一次，而水的各步读旧值。** 源码里的注释说得很明确：身体针对体温所做的**一切**——把水和
盐以汗的形式排掉——都由它在这刻开始时的体温驱动，所以每一步读的是前一状态，而新体温在最后只写一次。
读新体温会让发热去针对一个身体还没到达的体温出汗。

### 16.1 从刻到效果：Kotlin 侧的节奏

以上都是按刻计。**§15 的症状量级是按*效果结算*计的**，而一次结算不是一刻——这是本文里模型的数字
唯一遇到 Kotlin 胶水里那个数的地方，所以值得精确说明。

`AlimentSymptoms.tick` 每服务器刻走一遍所有在线玩家来推进身体，但它只在共用计数器是间隔的整数倍时
才**施加效果**：

$$c \bmod 40 = 0 \qquad (\texttt{EFFECT\_INTERVAL\_TICKS} = 40)$$

每个效果随后被施加 $40 \times 3 = 120$ 刻。这个分离是刻意的：不再需要的效果会自己**失效**，而不用
去跟踪并移除它。模型看不到这两个数中的任何一个——它只被问"伤害是多少"，并按结算回答。

**这个计数器与视角摇晃共用，所以节奏并不是干净的 $40$ 刻。** 同一个 `shakeCooldown` 字段 $c$ 被效果
结算读取，又被 `rollShake` 写入——后者从 `SHAKE_INTERVAL_TICKS` $= 300$ 往下数，到零时重置：

$$c \leftarrow \begin{cases}
c - 1, & c > 0 \\[4pt]
300, & c = 0
\end{cases}$$

所以计数器在 **$301$ 刻**里从 $300$ 走到 $0$ 然后重启，而结算发生在计数器值为 $40$ 的倍数的每一刻。
那些值是 $0, 40, \ldots, 280$——一共**八个**，因为 $300$ 不是 $40$ 的倍数：

$$\left\lfloor \frac{300}{40} \right\rfloor + 1 = 7 + 1 = 8, \qquad 300 = 7 \times 40 + 20 .$$

所以真实节奏是

$$\frac{\text{每周期 } 301 \text{ 刻}}{\text{每周期 } 8 \text{ 次结算}} = 37.625 \text{ 刻一次结算}$$

而不是 KDoc 里写的 $40$。一个周期内的模式并不规则——先七个 $40$ 刻的间隔，然后是一个 $21$ 刻的间隔
（当摇晃的重置正好落在一个 $40$ 的倍数之后）——长期平均比干净的 $40$ 刻结算

$$\frac{40}{37.625} - 1 \approx 6.3\%$$

更快。这是共用计数器带来的涌现性质，不是谁选定的数字，在引用每秒速率之前值得知道这一点。

以 $37.625$ 刻一次结算换算，结算速率为

$$\frac{20 \text{ 刻/秒}}{37.625 \text{ 刻/次}} \approx 0.5316 \text{ 次/秒},$$

所以模型数字对应到玩家的体验如下：

| 模型值 | 每次结算 | 每秒 | 游戏内结果 |
| --- | --- | --- | --- |
| $D_{\text{脓毒症}} = 1.0$（载量 60） | 1.0 | 0.5316 | 约 37.6 秒打光十颗心 |
| $D_{\text{脓毒症}} = 1.5$（载量 80） | 1.5 | 0.7974 | 约 25.1 秒 |
| $D_{\text{脓毒症}} = 2.0$（载量 100） | 2.0 | 1.0632 | 约 18.8 秒 |
| 血糖 $1.0$ 时的 $D_{\text{低血糖}}$ | 0.3 | 0.1595 | |

Minecraft 的血条是 $20$ 点。源码自己的 KDoc 里那句取整过的"每两秒半颗心"，描述的是一个理想化的
$40$ 刻结算，对玩家而言大约乐观了 $6\%$。

**摇晃有自己的间隔。** `rollShake` 在计数器归零的那一刻投一次 $\chi$，也就是每 **$301$ 刻
（$15.05$ 秒）**一次——所以 §15.3 的概率是每 $15$ 秒投一次骰，不是每次结算、也不是每刻，而
$\chi = 0.2$ 意味着大约每 $75$ 秒颤一次。

## 18. 数值说明

**钳制到处都是，而且它们是承重的。** 几乎每一步都以 $\mathrm{clamp}$ 或 $\max(\cdot, 0)$ 结尾。
这不是防御性的填充：模型没有稳定性证明，而若干项（死区以下的出汗抛物线、内源胰岛素摄取、药物衰减）
在没有它们的情况下会变负或冲过头。一个删掉钳制的改动应当被当作**动力学**的改动，而不是清理。

**欧拉法在这里绰绰有余。** 模型里最快的量是致热原与门冬胰岛素，都以 $2.5\times10^{-3}$ 每刻衰减，
而最快的状态相关速率是裸盖菇素转化，$1.083\times10^{-4}$。显式欧拉法对
$x \leftarrow x(1-k)$ 形式的衰减在

$$1 - k \in (-1, 1) \;\Longleftrightarrow\; 0 < k < 2$$

时稳定，所以模型离这个极限还有两个数量级以上的余量。三个 `approach` 常数（$0.002$、$0.0005$、
$0.0004$）都远小于 $1$，所以它们没有一个会超调。

**一切都是单精度的。** 模型全程 `Float`，这也是 Minecraft 那一侧存储的精度。长时间模拟累积的漂移
是真实存在的，但被钳制挡住了上限，而自测试在漂移可能有影响的地方断言的是**范围**与**方向**而不是
长期精确值——那些钉住精确数字的断言（五天掉水、十五天掉碘、"五天 $80 \to 40$"）都短到浮点误差
够不着它们的容差。

**只有一个量是比值而不是水平量**，就是 $\phi = \varepsilon/85$。它是清除速率真正想要的形状，所以
这个除法只做一次，而不是在每个调用点做——而读取它的速率不可能忘了做。

**存在两处刻意的间断**，两者都在其所在处有注释：

1. 免疫已启动时 $\lambda = 20$ 处的 $S$ 断崖（§6.1）。
2. 每一个写成阶梯而不是斜坡的阈值——两种药物发热（§8.1）、最后一个节点之后的三段 CYP3A4 平台
   （§14），以及免疫摇晃因子（§15.3）。

这些阶梯是关于模型**含义**的刻意选择，而不是对某个更平滑东西的近似，所以它们在每一处都被如此注释。

## 19. 要改什么去哪里

| 想改 | 改哪里 | 注意 |
| --- | --- | --- |
| 某个阈值或速率 | `Model.scala` 里的 `ModelConstants` | 文档与自测试里引用的那个数字 |
| 某条曲线的形状 | `Physiology.scala` | 那些局部的 `private final val` 是模型的一部分，不是可调旋钮 |
| 某个参考范围 | `MineralRanges` | $\rho$ 除以 $x_n$，所以改 $x_n$ 会挪动所有排名 |
| 介质权重 | `MediatorLevels` | 它们必须和为 $1$，且静息集必须复现 $J = 25$ |
| 某种食物的强度 | `AlimentIngestion`（Kotlin） | 那是食物表，不是模型；模型只定义"一份植物性食物"值多少 |

**数字属于 Scala。** 如果一个值在分界两侧都要用，它进模型，再通过 `AlimentModelBridge` 重新导出，
而那个文件自己不能含任何数字。自测试在 `AlimentPhysiologySelfTest` 里，是以上一切的权威规范；如何
运行见 [tools/README.md](../tools/README.md)。
