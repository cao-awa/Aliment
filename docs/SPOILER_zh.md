# 剧透 SPOILER

**Aliment（供养）** 是一个关于生理、疾病、药物与传染的模组。

下面全部都是剧透：隐藏的阈值、合成链路、画面效果，以及那些把数字打印出来的指令。
如果你更愿意自己琢磨"海水为什么一开始什么都没发生、后来却把人毁掉"，或者"生柳树皮汤为什么
会让你生病"，那就从这里打住。

## 30 秒版本

吃坏东西**不会**扣你的血。感染跑在一条曲线上：病原体按逻辑斯蒂增长，而免疫系统**只在中间那一段**
满效率工作。炎症太低就没有东西在打仗；太高则反应本身就是病。

所以这个游戏玩的是把炎症（柳树皮汤里的水杨苷、地塞米松注射剂）、水量、电解质、碘、维生素 C
和核心体温都维持在各自的窗口里——并且不喝没处理过的沼泽水、不站在牛群里。

## 2. 柳树

**长在哪里。** 只在河边，长在岸上，绝不长在水里——见 §1。树苗可种在泥土、草方块、耕地、砂土和泥上，
可以用骨粉。

**两种树形。** 树苗按 **65% / 35%** 在垂柳（树干 5–7）与高柳（树干 8–10）之间二选一。两者树冠相同，
半径 3。

**它会倾斜。** 自定义的树干生成器会在 7 格范围内寻找水面，把树干朝它能看到的水最密的一侧弯曲
1–4 格，所以柳树会朝它生长的那条河探出去。附近没有水时它直立向上。

**它会垂挂。** 垂柳藤（`willow_vines` 末端、`willow_vines_plant` 中段）在树冠下方悬 1–3 格，
并随时间向下生长；骨粉能加快它。

**柳树树叶永远不结苹果。**

## 3. 柳树皮与柳树皮汤

```
原木或木材 ──斧头右键剥皮──> 去皮原木/木材 + 柳树皮 ×1
柳树皮 ──砂轮──> 柳树皮碎片 ×2
柳树皮碎片 ──右键水炼药锅──> 生汤炼药锅
                                │ 下方放篝火或灵魂篝火，60 秒
                                ▼
                           熟汤炼药锅
                                │ 玻璃瓶 ──> 瓶装汤
                                │ 碗     ──> 碗装汤
```

* **炼药锅的水位就是份数。** 盛出一份，水位降一级；盛空后留下一个空炼药锅。破坏有汤的炼药锅
  只会掉出一个空炼药锅，别的不掉。
* **熬煮会暂停，不会重置。** 把火移开，那 60 秒的计时就停在原地；把火放回去，它接着走。
* 生汤浑浊浅淡；熟汤深浓、清亮、有香气。

| 汤 | 饱食度 | 饱和度 | 效果 |
| --- | --- | --- | --- |
| **生汤**（瓶装、碗装或加盐版） | 1 | 1 | **25% 反胃** 与 **15% 饥饿**，各持续 20 秒，**30% 细菌感染**，+1.1 水杨苷，+15 水量 |
| **熟汤**（瓶装、碗装或加盐版） | 1 | 2 | **安全**，+1.1 水杨苷，+15 水量 |

## 4. 盐

```
岩盐矿（地下 y=20–90，石镐可挖，掉落自身）
   └─砂轮─> 粗盐 ×9 ──砂轮──> 粗盐粉
                                 └─右键水炼药锅─> 粗盐水炼药锅
                                                     │ 下方放篝火
                                                     │ 每 20 秒推进一级
                                                     ▼ 烧干
                                                 盐粉 ×1
```

* **搅拌棒**（两根木棍，竖着放）右键粗盐水炼药锅，把它往前推进一级蒸发，代价是 1 点耐久（16 次）。
* **粗盐水在任何阶段都不吃水。** 往里加水不会稀释它——浓度看的是阶段而不是水位——只会白白毁掉这一锅。
  粗盐水炼药锅唯一接受的东西就是搅拌棒。
* **粗盐带着岩石一起来**：除了钠和氯，它还补一点镁和钙。精盐几乎是纯氯化钠，所以更容易把钠推高。
* **每一份加盐饮品都补水（+15）并补钠。** 粗盐版本还额外带着那些矿物。
* 水、蘑菇煲、柳树皮汤和生柳树皮汤都有加盐版本。
* **给普通水加盐时必须用真正的水瓶。** 药水里搅盐不是盐水，所以这个配方不会接受药水——
  一瓶治疗药水放进去，不会变成盐水出来。沼泽水与海水的加盐版本写的是各自的瓶子，从头到尾就不吃任何药水。

## 6. 水与口渴

* 生命值上方有一条 **10 格口渴条**；每格 10 点水量。
* 健康区间是 **30 – 100**，上限 200，静息的身体停在 80。
* **每份饮品 +15 水量**——水瓶、药水、蘑菇煲、牛奶、两种柳树皮汤、葡萄柚汁，以及它们的加盐版本。
  葡萄柚片是例外，**+5**：果片是吃下去的而不是喝下去的，所以拿不到一整份饮品的量。
* **从满到空（100 → 0）在温带静息状态下要 5 个游戏日。**
* **发烧喝得更快**：39.0 °C 时 3.5 天见底，40.0 °C 时 2.0 天。
* **超过 100 就是过水**：虚弱、挖矿变慢、更快疲惫，电解质被稀释。超过 150 再加反胃。

从哪里装瓶，决定里面是什么。

| 水 | 效果 |
| --- | --- |
| 沼泽水（含加盐版） | 30% 细菌感染、35% 反胃、5% 中毒，各 30 秒 |
| **海水**（含加盐版） | **当场什么都不会发生**。它只是高渗水：一瓶把钠从 140 推到约 143.5 mmol/L，仍在 135–145 之内；第二瓶就越过上限——随之而来的是剧渴与快速失水 |

## 7. 电解质与微量元素

电解质用 **mmol/L**，微量元素用 **µmol/L**，配的是验血单上会打印的那套参考范围。

| 矿物质 | 健康 | 参考范围 | 单位 |
| --- | --- | --- | --- |
| 钠 | 140 | **135 – 145** | mmol/L |
| 钾 | 4.2 | **3.5 – 5.0** | mmol/L |
| 镁 | 0.85 | **0.70 – 1.00** | mmol/L |
| 氯 | 101 | **96 – 106** | mmol/L |
| 钙 | 2.35 | **2.10 – 2.60** | mmol/L |
| 碘 | 0.50 | **0.25 – 0.80** | µmol/L |
| 维生素C | 60.0 | **40.0 – 80.0** | µmol/L |

五项电解质会自己找路回家。**碘和维生素 C 不会**——见下文与 §15。

* **碘只会往外走。** 从正常的 0.50 起每天流失 0.09，正好 **5 个游戏日**掉光；一天一份海带差一点点，
  两份才舒服。甲状腺会读它，但参考下限刻意压到 0.25——**症状从 0.25 才开始**，所以设定点在碘掉到
  0.25 以下之前根本不动，到 0.05 的下限时低了 0.8 °C——这就是缓慢 II、虚弱 II 与疲劳背后的重度甲减。
  超出正常值的碘会因为自身浓度偏高而排得更快一点，所以超量不会长期堆积。
* **猛喝水最先冲掉的是钠**，然后是氯；镁和钙最后。
* **一份粗盐制品是 +3.0 mmol/L 钠，一份精盐制品是 +3.5。** 两份加盐制品会把健康的 140 推到
  146–147，并带来随之而来的口渴。

| 矿物质 | 重度不足 | 轻度不足 | 轻度过量 | 重度过量 |
| --- | --- | --- | --- | --- |
| 钠 | 反胃 + 缓慢 | 虚弱 | 饥饿（剧渴） | 饥饿 + 虚弱 |
| 钾 | 虚弱 II + 挖掘疲劳 | 虚弱 | 虚弱 | 缓慢 II + 周期性魔法伤害（心律不齐） |
| 镁 | 虚弱 + 缓慢（震颤） | 虚弱 | 缓慢 | 缓慢 + 虚弱 |
| 氯 | 反胃 | 虚弱 | 饥饿 | 饥饿 + 反胃 |
| 钙 | 缓慢 + 虚弱（手足抽搐） | 虚弱 | 缓慢 | 缓慢 II + 虚弱 |
| 碘 | 缓慢 II + 虚弱 II + 疲劳 | 虚弱 + 缓慢 + 饥饿 | 饥饿 + 反胃 | 再加虚弱 |
| 维生素C | 挖掘疲劳 + 虚弱 | 挖掘疲劳 | 无——安全排出 | 无——安全排出 |

## 8. 免疫系统

炎症是五种介质的加权合成，健康时以 **25.0** 为中心。

| 介质 | 作用 | 被谁压低 |
| --- | --- | --- |
| 组胺 | 血管扩张、瘙痒、肿胀 | 两者都略微压低 |
| 前列腺素 | 疼痛与**发热** | **水杨苷** |
| 白三烯 | 支气管收缩、黏液 | **地塞米松** |
| 细胞因子 | 全身发热、风暴的主驱动 | **地塞米松**（最强） |
| 缓激肽 | 疼痛、血管通透性 | 水杨苷 |

| 区间 | 会发生什么 |
| --- | --- |
| **< 12** | 免疫瘫痪：感染不受阻拦地增长，机会性细菌会自己冒出来 |
| **20 – 40** | 清除效率最高 |
| **> 75** | 细胞因子风暴：清除失败，受伤的是你自己的组织 |

这就是整段张力的一句话总结：**抗炎药吃过量和感染一样危险**，因为把反应压到 12 以下，
病原体就撒开了跑。

## 9. 感染

| 来源 | 病原体 | 概率 | 载量 |
| --- | --- | --- | --- |
| 生肉（所有生肉）、腐肉、毒马铃薯 | 细菌 | **30%** | +6 |
| 生柳树皮汤，含加盐版 | 细菌 | **30%** | +6 |
| 走到**任何活着的生物** 2 格以内 | 病毒 | **每秒 5%** | +5 |
| **炎症 ≤ 12** | 细菌 | **每秒 15%** | **+4 到 +12**，随机 |

* 近距离判定对的是**每一个活着的 `Mob`**——牛、狼、村民、蝙蝠。站在一群里是最快中招的方式。
* **免疫抑制会让你从自己的菌群被殖民**，完全不需要传染源。
* **败血症：从载量 60.0 起**，每两秒一次无法抵挡的魔法伤害：

  ```scala
  val damage = 1.0f + (load - 60.0f) / 40.0f
  ```

  载量 100 时那就是 2 点伤害——一整颗心——每十秒一次。

| 香柠檬素 | 葡萄柚片 | 每片 +1 | 上限 10 时 1 个游戏日 | 见 §14 |

水杨苷是 COX 抑制剂：它是退烧药，因为它阻断前列腺素的合成。地塞米松掐断细胞因子转录、中止风暴。
**两者都不直接杀死任何东西**——它们只是给免疫系统腾出空间。真正在杀的是黄连素和甘草酸，见 §20。

门冬胰岛素则是一剂药的反面：它是唯一一种**故意**把身体弄得更糟的药。见 §13。

## 11. 体温调节

| 状态 | 核心体温 |
| --- | --- |
| 正常 | **37.0 °C** |
| 舒适 | 36.0 – 38.5 °C，无任何症状 |
| 发烧 / 超高热 | **≥ 38.5 °C** / **≥ 40.0 °C** |
| 轻度 / 重度失温 | ≤ 36.0 °C / ≤ 35.0 °C |

体温是感染热原、注射热原、甲状腺活动与环境相加的结果。

| 环境 | 稳定在哪里 |
| --- | --- |
| 温带群系 | 无影响 |
| 沙漠 | 约 37.4 °C |
| 雪原 | 约 36.6 °C，无任何症状 |
| 在寒冷群系里浸没 | 约 35.1 °C，**轻度失温** |
| 湿着身子埋在细雪里 | 约 32.8 °C，**重度失温** |
| 着火 | 约 38.2 °C，亚发烧 |
| 在岩浆里 | 约 39.4 °C，**发烧**，带热浪 |

炎热群系加上一个运转的甲状腺可以在完全没病的情况下到 38.0 °C；发烧症状严格从 **38.5 °C** 开始。

状态栏上也会直接写明你处在哪一档，所以诊断指令不再是唯一的查看方式。这两个都只是提示，没有任何别的用途——
它们不会对身体产生任何影响，也不带持续时间。

| 效果 | 从何时出现 | 等级 |
| --- | --- | --- |
| **发热** | ≥ 38.5 °C | 38.5 为 I、39.5 为 II、40.0 为 III |
| **疼痛** | ≥ 39.5 °C | 只有一级 |

发烧的三档自成一套刻度，并且**刻意不同于**症状刻度：虚弱与挖掘疲劳是在 38.5 升一档、在 **40.0** 再升一档，
所以从 39.5 开始显示的 **发热 II** 是在告诉你病得多重，而不是又有别的什么落在了你身上。
这两个图标在状态栏上停留的时间，正好等于体温把它按在那里的时间——旁边没有倒计时，
因为结束一场发烧的是身体降温，而不是计时器走完。

## 12. 画面效果与镜头抖动

全屏着色器**只扭曲画面边缘**（`smoothstep(0.45, 1.0, ...)`），所以准星和画面正中间保持干净。

| 效果 | 触发 | 看起来像 |
| --- | --- | --- |
| 热浪扭曲 | ≥ 38.5 °C | 边缘泛红波动 |
| 热模糊 | ≥ 40.0 °C | 热浪之上再加运动模糊拖尾 |
| 冷颤 | ≤ 36.0 °C | 更慢的垂直抖动，泛蓝 |

**镜头抖动**每 **15 秒**掷一次，命中时抖 16 tick。上表每一种来源都会在效果栏里留下图标，
所以抖动从不会是没来由的。

| 来源 | 概率 |
| --- | --- |
| 有症状的感染 | 20%，细胞因子风暴期间翻倍 |
| 每偏离舒适区一档温度 | +15%，幅度也更大 |
| 镁偏低 | +15% |
| 钙严重偏低 | +20% |
| 碘过量（心悸） | +10% |
| 严重过水，且带反胃图标 | +10% |

38.0 °C 以下，以及水量在 100 到 149 之间，什么都不会抖。

## 13. 血糖与葡萄糖链路

血糖是身体**花掉**——而不是调节——的第二项资源，仅次于水量。没有地方储存余量，也没有地方合成它：
吃东西是唯一把它放回去的办法，所以一个不进食的玩家无论身体其他部分多健康都会见底。

| 项 | 值 |
| --- | --- |
| 正常、空腹 | **5.0 mmol/L** |
| 参考范围 | **4.0 – 5.5 mmol/L** |
| 空腹下限，2 个游戏日到达 | **3.5 mmol/L** |
| 胰岛素陡升 | **> 8.0 mmol/L** |
| 基准胰岛素指数 | **1.0** |

**食物值多少**

| 食物 | 血糖 |
| --- | --- |
| 面包，以及葡萄柚汁 | **+0.7** |
| 熟肉与熟鱼 | **+0.5** |
| 生肉与生鱼 | **+0.4** |
| 植物性食物——水果、蔬菜、海带、海藻、蘑菇、柳树皮汤、葡萄柚 | **+0.4** |

一块面包就足以把一个正常的 5.0 推出参考范围——一块下肚身体会读到 5.7——一杯葡萄柚汁也一样，
因为搅进去的糖就是快吸收碳水。除此之外，所有能吃的、不是肉的东西都算植物性食物，所以靠浆果
过日子并不能绕开进食的血糖代价。

* **一顿饭在半个游戏日内就没了，而更大的那顿掉得更快。** 胰岛素指数横跨参考范围一路爬升，
  越过 8.0 之后陡一倍，所以 20 mmol/L 的一次冲高在同样的时间里比 9 掉得更多。没有任何一次会过冲进
  低血糖，因为身体自己的胰岛素在参考范围底部就关掉了。
* **空腹的头两个游戏日花掉 1.5 mmol/L**（5.0 → 3.5），之后花得更少：过了下限，下降按剩下的量缩放，
  而不是一路直冲到零。
* **低血糖：**

  | 血糖 | 效果 |
  | --- | --- |
  | < 2.0 mmol/L | **挖掘疲劳** |
  | < 1.7 mmol/L | 挖掘疲劳 **+ 虚弱** |
  | < 1.3 mmol/L | 以上全部，再加每两秒一次的**魔法伤害**：`(1.3 - glucose) * 1.0` |

  伤害无视护甲——大脑除了葡萄糖没有别的燃料。八个游戏日不进食会把身体留在 **0.97 mmol/L**，
  那是一场危机。
* **和平难度下血糖完全不会移动。** 四条进入路径一起关掉：空腹消耗、身体自身的胰岛素、注射的剂量、
  以及食物。它是**按住**而不是重置，所以不能用来给自己补血糖——而已经处在崩溃中的身体会继续崩溃，
  因为唯一能抬高血糖的那条路和其余的路径一起关掉了。不过它仍然只是难受而不是致命：
  崩溃每秒索要 0.4 点伤害，而和平模式在生命值未满时每秒回复 **1.0 点**，所以血条停在满值。
  `/aliment cure` 与把难度调回去都能结束它。`/aliment status` 会在那一行标上
  **`[held: peaceful]`**，以免这个已经不再说明任何事情的数字被当成正常读数。

### 四件物品

| 物品 | 箱子 | 说明 |
| --- | --- | --- |
| `aliment:insulin_injection` | **10%** | 右键；**+10.0** 门冬胰岛素，上限 60.0，一个游戏日内清完 |
| `aliment:glucose_meter` | **35%** | 读取另一只手上的带血试卡 |
| `aliment:glucose_test_strip` | **35%**，每叠 5–9 张 | 在流血的手指上变成带血试卡 |
| `aliment:microneedle` | **35%** | 扎破手指，之后流血 **15 秒**（300 tick） |

四样都生成在每一种原版村庄箱子和掠夺者前哨站的箱子里。带血试卡从来不是捡到的——它是玩家自己做出来的。

**诊断链。** 用微针扎破手指，趁它还在流血时用试卡右键（血滴干后再用会被拒绝），
然后**主手**持血糖仪、**副手**持带血试卡右键。读数会打印在聊天栏里——`Blood glucose: 5.1 mmol/L`
——试卡随即被消耗。

**带血试卡是样本，不是传感器。** 它存的是**取血那一刻**玩家的血糖，之后无论过多久再读都报这个值
——所以一张试卡可以在饭前扎、饭后读，可以放进箱子，也可以交给别人，而它仍然代表它原来的意思。
只有完全没有样本的试卡，才会退回到身体当前的血糖。

**门冬胰岛素不是治疗。** 与身体自己的胰岛素不同，它在参考范围底部不会被关掉，所以正常身体打一针
是一次能扛过去的下探，约 2.7 mmol/L，打两针就是危机。唯一的出路是吃东西。

## 14. 葡萄柚与 CYP3A4

葡萄柚是模组里第一个**会改变另一样物质持续多久的食物**。香柠檬素本身没有效果：它做的一切，
都是通过压低清除黄连素的那个肝酶来完成的。

### 树

| | |
| --- | --- |
| 在哪里 | 丛林与热带草原，稀有度 1/6——见 §1 |
| 树干 | `aliment:grapefruit_log`，4–6 格，球状树冠半径 2 |
| 果实 | `aliment:grapefruit`，挂在 30% 的合格树冠叶片下 |
| 树苗 | `aliment:grapefruit_sapling`，长出同样的树 |

果实是**悬挂方块**：原版的 `minecraft:attached_to_leaves` 装饰器把它放在树冠叶片正下方那一格，
而且只有上方仍是树叶或原木时它才存在。砍掉树冠会把整片果实一次打落。破坏一个掉落果实，
一个果实能合成 **8 个果片**。

### 果片

| | 每片 |
| --- | --- |
| 饱食度 | **2** |
| 饱和度 | **3 点** |
| 水量 | **5** |
| 香柠檬素 | **1** |
| 维生素 C | **10 µmol/L**，和胡萝卜一样 |
| 随时可食 | **是**——一剂药不该等到肚子空了才能吃 |

果片是模组里唯一一种还能补水的食物——一份零食干了一杯饮品的活，代价是只有三分之一。
十个果片就填满身体的香柠檬素。它也是少数**饱腹时仍可食用**的食物之一，因为玩家吃它是为了香柠檬素，
而不是为了那点饱食度。

### 果汁

糖、一个果片、一个**水瓶**——不是任意药水——合成一杯**葡萄柚汁**。它就是果片被压进了瓶子里：
同样的香柠檬素、同样的维生素 C，但它是**喝**下去而不是吃下去的，所以它还能拿到一整份饮品的水量。
糖是它唯一额外带来的东西。

| | 葡萄柚片 | 葡萄柚汁 |
| --- | --- | --- |
| 饱食度 | 2 | **0**——是饮品，不是一顿饭 |
| 水量 | 5 | **15**，标准饮品量 |
| 香柠檬素 | 1 | **1** |
| 维生素 C | 10 µmol/L | **10 µmol/L** |
| 葡萄糖 | 0.4，按植物性食物 | **0.7**，按糖算 |
| 随时可食 | 是 | **是** |

所以当你也在意水量时，该喝的是这一杯；而它的葡萄糖按面包计、不按它所压榨的水果计：
一杯让身体从 **5.0 读到 5.7**，和一块面包迈的是同一步。十杯仍然是香柠檬素上限，与十个果片
完全一样——这一杯改变的是水量与葡萄糖，不是剂量。

### 木材

这棵树是完整的**第二套木材**，而不只是一棵果树：

| | |
| --- | --- |
| 原木形 | `grapefruit_log`、`grapefruit_wood`、`stripped_grapefruit_log`、`stripped_grapefruit_wood` |
| 木板 | `grapefruit_planks` |
| 型材 | 楼梯、台阶、栅栏、栅栏门、门、活板门、压力板、按钮、架子 |
| 告示牌 | 立式、墙上、悬挂、墙上悬挂 |
| 船 | `grapefruit_boat` 与 `grapefruit_chest_boat`，各自拥有独立的实体类型 |
| 装饰 | `potted_grapefruit_sapling` |

四种原木形方块在它们自己的 `aliment:grapefruit_logs` 标签里，木板配方取用的正是这个标签——
所以葡萄柚木板配方无法用柳木原木满足，两种木材在整棵合成树上一路都是分开的。
其余的都加入原版的 `planks`、`logs`、`wooden_*`、`signs` 与 `fence_gates` 标签，
这正是这一套能用斧开采、也能被原版配方识别的原因。

### 酶

CYP3A4 在从未吃过葡萄柚的身体里是 **85**，而香柠檬素是**沿曲线**把它压下去的，不是一档一档跳，
所以每吃一片都会再拿走一点；下面这些是它经过的取值点，而不是它只能取的几个值：

| 香柠檬素 | CYP3A4 | 黄连素被清除的速率 | 所以一份药能撑 |
| --- | --- | --- | --- |
| 没吃 | **85** | 1.00x | 1.0x |
| 2 片 | **60** | 0.71x | 1.4x |
| 4 片 | **45** | 0.53x | 1.9x |
| 7 片 | **25** | 0.29x | 3.4x |
| 8.5 片 | **10** | 0.12x | **8.5x** |

超过八片半之后指标不再下降，所以抑制就到这个深度为止。

香柠檬素从上限起在**一个游戏日**内线性清完，所以这个效果会自己消退——而最后一列也只在剂量
生命的一部分时间里才拿得到。

### 它是干什么用的

黄连素——来自黄连与黄柏——是模组的抗菌成分，而且只由 CYP3A4 清除，没有别的途径。一份黄连单独吃下去
约 **9,400 tick** 清完；在九个葡萄柚片之后再吃同一份，就要约 **20,100**。这是一把双刃剑：
葡萄柚既是玩家把手头不多的药材拉长用的办法，也是玩家在只想吃一次的时候把自己搭进去的办法。
没有葡萄柚就没有相互作用——干净的身体清除黄连素的速度和它一直以来完全一样。

## 16. 曼陀罗

一种四个生长阶段的茄科植物，种在**土里而不是耕地里**——它是 `BushBlock`，不是作物，所以不需要
耕地（不过耕地也能用）。野生分布见 §1。

* **种它：** 在草方块、泥土、粗泥、扎根泥土、泥、苔藓或耕地上。随机刻在光照等级 9 或以上推进它，
  八次里走一步；骨粉每次推进一个阶段，三次成熟。
* **采收：** 只有**成熟**的植株才掉东西——1–2 个果实，受时运影响。未成熟植株什么都不掉。
* **种子：** 一个果实合成 **2 颗种子**，所以一次发现就能变成一座农场。

两种生物碱上限都是 **5.0**，在 **1 个游戏日**内线性清完：

```scala
scopolamine = Math.max(scopolamine - 5.0f / 24000f, 0f) // -2.083e-4 / tick
atropine    = Math.max(atropine    - 5.0f / 24000f, 0f) // -2.083e-4 / tick
```

| 吃下 | 东莨菪碱 | 阿托品 |
| --- | --- | --- |
| 曼陀罗果实 | **+1.0** | **+0.1** |
| 曼陀罗种子 | **+0.75** | **+0.1** |

两者相加，而这个和会驱动一场**水杨苷碰不到**的自己的发烧——它和前列腺素毫无关系：

```scala
val deltaT =
  if (alkaloidSum >= 4.0f) 4.0f      // 核心体温 -> 41.0 °C
  else if (alkaloidSum >= 2.5f) 2.5f // -> 39.5 °C
  else if (alkaloidSum >= 1.5f) 1.0f // -> 38.0 °C
  else 0.0f
```

一旦 `scopolamine >= 2.3` 或 `atropine >= 2.3` 或两者之和达到 `2.7`，视觉就会模糊——雾被拉到 8 格。
药物性发热与模糊会叠加在感染已经在做的任何事情之上。

## 17. 橘黄裸伞

一种长在潮湿荫蔽林地里的锈色木腐蘑菇——见 §1。因为它腐的是木头而不是土壤，
它**完全无视原版蘑菇的黑暗规则**，在开阔的天光下和树干上都能长。

* **生的：** 1.3 裸盖菇素 + 1.3 裸盖菇素醇，以及 3 饱食度 / 4 饱和度。
* **熟的**（熔炉、烟熏炉或篝火）：4 饱食度 / 5 饱和度，而且**完全没有致幻成分**——热把它们毁掉了。
* **动力学：** 裸盖菇素本身什么都不做；它在半个游戏日内 1:1 转化成裸盖菇素醇，
  而裸盖菇素醇以固定速率清除。

  ```scala
  val converted = Math.min(psilocybin, 1.3f / 12000f)          // 1.083e-4 / tick
  psilocybin -= converted
  psilocin = clamp(psilocin + converted - (1.3f / 24000f), 0f, 10.0f) // -5.417e-5 / tick
  ```

  五朵生蘑菇就是一场持续十个游戏日的旅程，线性。

| 裸盖菇素醇 | 你会看到 |
| --- | --- |
| > 1.2 | 方块边缘射出彩色线条 |
| > 1.7 | 方块上的色彩偏移，以及全屏彩色噪点 |
| > 2.5 | 轻度全屏空间扭曲 |
| > 5.0 | 剧烈扭曲，以及一场爬到 39.0 °C 的药物性发热 |
| ≥ 7.0 | 超高热，41.0 °C |

## 18. 酿酒与蒸馏

**发酵罐。** 顶部中央围着任意木板铺一圈玻璃。有三个水位（0–3）；加入 **糖 ×1** 和
**酿酒酵母 ×1**，它会冒泡 45 秒（900 tick）变成 **7% 的酒**，用玻璃瓶舀出来。瓶子会把自己的浓度
一起带走，而**达到 70% 以上时它叫「酒精」而不是「酒」**。

**葡萄醪。** 同一个发酵罐还能酿出第二种更淡的酒。往水里加入 **葡萄 ×1** 和 **糖 ×1**（先后顺序
随意，液体会变成紫色），最后加酵母。这里的糖是**补全**葡萄醪而不是替换它：**两样都放进去之前酵母
会被拒绝**，因为葡萄大部分是水，真正发酵的是糖。45 秒后罐里就是 **5% 的葡萄酒**，直接装瓶，不需要
蒸馏器。葡萄和糖都会被消耗掉，罐子重新空出来。

顺序无关紧要。先放葡萄，罐子就是一份等糖的葡萄醪；先放糖，是普通的酒，随后放进的葡萄会把它提升为
葡萄醪。两种顺序下，酵母都要等两样齐了才会生效，产物也都是 5% 的葡萄酒而不是 7% 的酒。

**已经发酵过的罐子不再吃水。** 往里补水不会稀释酒精，因为罐子存的是一个**浓度**而不是总量——加进去
的水出来还是满浓度的酒。装一瓶、补满三格、再装三瓶，一份糖和酵母就能灌满整个世界。发酵结束那一刻
罐里有多少水，这一批就是多少；全部装瓶之后罐子空了，才可以重新加水。

| 水里的东西 | 产物 | 乙醇 | 需要蒸馏器吗 |
| --- | --- | --- | --- |
| 糖 | 酒 | 7% | 要到 40% 才需要 |
| 小麦 | 啤酒 | 7% 的醪 | **需要**——麦醪不能直接装瓶 |
| 葡萄 + 糖 | 葡萄酒 | **5%** | 不需要——出罐即可装瓶 |

**葡萄从哪来。** 平原与温带森林里的野生葡萄藤（见 §1），或者从果实取种：一个葡萄在合成格里
给出两颗种子，像曼陀罗一样种进泥土、草方块、耕地或砂土，用骨粉走完四个阶段。成熟的藤要**右键**
采收葡萄并退回 `age=1` 而不是枯死，所以葡萄藤是「留下来、走回来」的作物；这与原版的甜浆果丛
完全同形。右键固定给 **1–3** 个且不吃时运，这也与原版一致——原版甜浆果丛的采收表不带加成，
方块表才带。直接破坏成熟的藤仍然给 1–3 个葡萄、而且**仍然吃时运**，因为葡萄藤本身没有对应物品；
所以带时运的工具更适合破坏，而右键是「想把植株留下」时的做法。提前采就是浪费一颗种子：
`age=3` 之前两种收法都不掉任何东西，而且此时右键会原样传递给手上的物品而不是被吞掉，因此骨粉
依然生效。葡萄本身也能吃：2 饱食度、1.0 饱和度、
随时可食。在砧板上切它、以及把葡萄柚煮成汁，这两个配方需要**农夫乐事**——见 §22，那个模组自己的
储藏室也在那里计价。

**酵母。** 无序合成：小麦 + 糖 + 棕色蘑菇。

**蒸馏器。** 两排水平摆放的玻璃，中间一排留空。把它放在由点燃的**篝火或灵魂篝火**加热的
发酵罐上方，每 30 秒（600 tick）就蒸发掉一个水位的酒：

* 单独一根竖直冷凝管的出口**朝上**。把它接到旁边的水平冷凝管上，出口就弯**朝下**——正是这才
  让它能把蒸汽滴进炼药锅，收集成 **40% 的烈酒**。
* 没对准的管子会把蒸汽嘶嘶地排进空气里，白白浪费掉那一级。

**饮用。** 酒恢复 **10 点水量**，而不是一份饮品的 15。它按 0.0–1.0 的刻度抬高乙醇指数：
7% 的酒是 +0.07，**5% 的葡萄酒是 +0.05**，40% 的烈酒是 +0.40。排除是零级的，每游戏日 1.0：

```scala
ethanol = Math.max(ethanol - 1.0f / 24000f, 0f) // -4.167e-5 / tick
```

| 乙醇 | 效果 |
| --- | --- |
| ≥ 0.35 | 反胃 I、缓慢 I |
| ≥ 0.70 | 反胃 II、缓慢 II |

一杯 7% 的酒是 +0.07，大约 **1.4 分钟**就醒酒。

## 19. 麻黄与麻黄碱

一种沙漠与草原灌木——它长在哪里、怎么采收见 §1。**右键一棵成熟的麻黄会给你 1–2 根枝条，
并把它退回第 1 阶段而不连根拔起**，所以一片麻黄是可再生的来源；破坏它给的枝条更多，
但代价是这株植物。

* **碎麻黄：** 砂轮，或者在合成格里用剪刀（消耗一点耐久）。
* **麻黄碱药水：** 玻璃瓶 + 碎麻黄，无序合成。瓶子会还给你。
* **剂量：** 一根生枝条是 +0.5，一瓶药水 +2.5，上限 5.0。

```scala
ephedrine = Math.max(ephedrine - 5.0f / 24000f, 0f) // -2.083e-4 / tick
```

* **急迫**来自 `ephedrine > 1.0`，所以一根枝条不够，一瓶药水够。满值 5.0 是连续十六分钟以上的急迫。
* **它让你睡不着。** 高于 **0.5** 时神经系统平静不下来，床会拒绝你——*"你无法在兴奋剂状态下睡觉"*。
  一根枝条正好落在阈值上，仍能入睡；第二根枝条，或任何一瓶药水，就不行了。随着药物代谢，
  这个限制会自己解除。

## 20. 传统药用本草

黄连、黄柏和甘草一起长在每一个非寒冷群系里——见 §1。

| 本草 | 生品 | 研磨 | 用水瓶酿造 |
| --- | --- | --- | --- |
| 黄连 `aliment:coptis` | **+1.1 黄连素** | 碎黄连 | **黄连药水**，+2.5 黄连素 |
| 黄柏 `aliment:phellodendron` | **+0.6 黄连素** | 碎黄柏 | **黄柏药水**，+1.5 黄连素 |
| 甘草 `aliment:licorice` | **+1.1 甘草酸** | 碎甘草 | **甘草药水**，+2.5 甘草酸 |

这些是模组里唯一**直接杀死病原体**的东西。对于 `0.0 .. 7.0` 的药物浓度，减速阈值在 1.5，
完全抑制在 3.0：

```scala
if (drugConc >= 3.0f) {
  // 复制就此停止，药物自身的清除速率随浓度缩放
  val drugClearance = (100.0f / (1.5f * 24000f)) * (drugConc / 3.0f)
  load = Math.max(load - immuneClearance - drugClearance, 0.0f)
} else if (drugConc > 1.5f) {
  // 复制被拖慢到免疫系统能赢的程度
  val slowRatio = (drugConc - 1.5f) / (3.0f - 1.5f)
  val reducedGrowth = baseGrowth * (1.0f - 0.75f * slowRatio)
  load = Math.max(load + reducedGrowth - immuneClearance, 0.0f)
} else {
  load = Math.max(load + baseGrowth - immuneClearance, 0.0f)
}
```

其中抑制清除常数是 `c_suppress = 100.0 / (1.5 * 24000) ≈ 2.778e-3` 每 tick。

* **黄连素针对细菌**：`berberine -= 7.0f / 60000f`（−1.167e-4 / tick），从上限起 2.5 个游戏日
  ——**除非体内有葡萄柚**，那正是 §14 讲的事。
* **甘草酸针对病毒**：`glycyrrhizin -= 7.0f / 48000f`（−1.458e-4 / tick），从上限起 2.0 个游戏日。

## 22. 农夫乐事

Aliment 不要求那个模组，也不打包它：依赖是**纯编译期**的。Aliment 针对它的食物编译，只是为了给它们
计价；没装它时游戏照样启动、照样玩、自检照样全过——下面两个配方只是根本不存在。这是集成，不是必需。

| 需要农夫乐事的配方 | 站点 | 产出 |
| --- | --- | --- |
| 用**刀**切一串葡萄 | 砧板 | 3 颗葡萄种子 |
| 一个葡萄柚片加糖，用**玻璃瓶**接出 | **烹饪锅** | 葡萄柚汁 |

**它的储藏室会喂给模型。** 吃就是吃，所以一顿农夫乐事的饭推动的数字和原版一样，而它全部 **80 种**

| 类别 | 计什么 | 例子 |
| --- | --- | --- |
| 腌肉 | **钠与氯** | 培根与火腿切片 +0.8，培根三明治或培根煎蛋 +1.2，蜜汁火腿 +2.0 mmol/L |
| 蔬菜与沙拉 | **维生素 C** | 番茄 +10，等于一根胡萝卜；卷心菜 +8，洋葱与南瓜片 +6；沙拉最富，+14 到 +18 |
| 海带卷 | **碘** | 一卷 +0.15 µmol/L，切片恰好是它的三分之一 |

## 23. 创造模式与死亡

**创造模式冻结整个系统。** 什么都不推进——病原体既不增长也不清除，体温不动，药物不代谢——
不施加任何效果，不造成伤害，不收挖掘惩罚，也不套用疲惫倍率。任何已经挂上去的画面效果
在下一个 tick 就被撤掉，抖动也随之停下。吃、喝、注射也都不起作用。这是**冻结，不是治愈**：
带着感染走进创造，你就会带着它走回生存。

**死亡重置身体。** 你带着一副新身体复活：炎症回到静息值、没有病原体、核心体温 37、水量 80、
碘回到正常值。死亡是唯一能把模型整个丢掉的途径。

## 26. 容易踩的坑

1. **海水不是脏水。** 喝下去当场什么都没发生；代价是那些钠，而且要两瓶才会越过参考范围。
2. **口渴条看不出过水。** 100 和 200 都画成十格满——要看的是虚弱图标。
3. **生柳树皮汤是感染源，熟汤不是。** 那 60 秒值得等。
4. **碘五天掉光，身体也不会留住它。** 一天一份海带不够，两份刚好；没有它你就会走进重度甲减
   和更低的体温设定点。多出来的部分同样存不住——只是排得更快一点。
5. **水杨苷同时是抗炎药和退烧药**，因为它阻断前列腺素，而发烧正是靠它跑的。
6. **过量用药比感染更危险。** 炎症低于 12 就是免疫抑制，而免疫抑制会**每秒 15% 凭空**
   给你一个随机细菌感染；载量一过 60，败血症伤害就开始了。这是唯一一条能用药物把自己杀死的路。
7. **别站在牛群里。** 2 格内的任何生物都是每秒 5% 的病毒判定。
8. **柳树树叶永远不结苹果。**
9. **每一次抖动都有原因**，而每一个原因在效果栏里都有一个图标。
10. **血糖只会自己往下掉。** 没有任何东西合成它，所以一个不进食的玩家两个游戏日里从 5.0 漂到 3.5，
    到第八天就是危机。面包值 0.7，其余都值 0.4–0.5。和平难度下它完全不移动，两个方向都不动——见 §13。
11. **胰岛素注射剂不是治疗手段。** 它降低血糖，而且没有任何东西会把它关掉；冷却期内两针就是危机，
    唯一的出路是吃东西。
12. **葡萄柚会改变你其他药的持续时间。** 九个果片能让一份黄连的持续时间几乎翻倍——既能拉长
    你手头不多的药材，也能让你把自己搭进一份你本来只打算吃一次的药里。它会在一个游戏日内自行消退。
13. **挂着的葡萄柚不是摘完就能不管的果子。** 它只在上方的树叶或原木还在时才存在，所以砍倒整棵树
    会一次打落整片果实——很方便，但这也意味着你在树冠里搭方块时果实撑不住。
14. **创造模式不会治愈你。** 它冻结模型；你回到生存时感染还在那里。
